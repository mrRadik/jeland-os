# Jeland OS

Бесплатный интерфейс для головного устройства Jeland J7 на Kotlin и Jetpack
Compose: климат, музыка, состояние автомобиля, офлайн-навигация и автоматизации.

**Автор и правообладатель — Файсханов Радик Ринатович (mrRadik).**

[Скачать APK](https://github.com/mrRadik/jeland-os/releases/latest) ·
[Сообщить об ошибке](https://github.com/mrRadik/jeland-os/issues) · [Лицензия](LICENSE)

## Возможности

- Главный экран с автомобилем, погодой, музыкальным и навигационным виджетами,
  избранными приложениями и быстрыми действиями.
- Светлая и тёмная темы; автоматическое переключение по состоянию штатного ГУ.
- Температуры двух зон, вентилятор 1–10, направления обдува, A/C, AUTO, SYNC,
  рециркуляция и доступные обогревы.
- Управление передними сиденьями, подогревом задних сидений и руля, панорамной
  шторкой; открытие штатных камер и настроек автомобиля.
- Состояние дверей и багажника, давление шин, топливо и напряжение аккумулятора.
- Музыка Bluetooth, CarPlay и USB, автоматический выбор источника, метаданные
  и обложки при наличии, список USB-композиций.
- Офлайн-карта, адресный поиск и организации, выбор здания касанием,
  маршрутизация, голосовые подсказки, история поиска и избранные точки.
- Сценарии с несколькими устройствами: ручной запуск, температурное условие
  либо запуск без него. Событие выбирается для каждого сценария:
  подтверждённая работа двигателя или начало движения.
- Автозапуск после загрузки/пробуждения, диагностика и очистка собственных логов,
  проверка обновлений через GitHub Releases.
- DEMO-режим без отправки команд автомобилю.

## Совместимость и ограничения

Разработка и проверка ведутся на **Jeland J7 со штатной системой Desay**.
Другие автомобили и прошивки требуют адаптации. Минимум — **Android 11 / API 30**;
устройство должно поддерживать ABI включённых нативных библиотек.

Приложение предоставляется «как есть» и не заменяет штатные системы безопасности.
Установку, настройку и первичную проверку управления выполняйте на стоянке.

- Штатная приборная панель не заменяется; прошивка автомобиля не изменяется.
- Температура шин зависит от доступности отдельного канала QNX. При отсутствии
  данных вымышленные значения не подставляются; есть отладочный экран.
- Пересчёт топлива и давления использует предварительные коэффициенты.
  Обороты двигателя не публикуются как достоверные: прежняя формула не подтвердилась.
- Некоторые команды могут кратковременно открывать штатную панель климата.
  Исследуется смена направления обдува после изменения скорости вентилятора.
- Новый поворот карты по курсу проверен программно; проверка этой правки в поездке
  на ГУ ещё предстоит.
- Работа автозапуска после сна зависит от прошивки и предоставленных разрешений.

## Установка

1. В [Releases](https://github.com/mrRadik/jeland-os/releases) скачайте
   `JelandOS-<версия>.apk` из раздела Assets.
2. Установите APK системным установщиком Android либо своим ADB-установщиком.
   При обновлении ставьте поверх прежней версии, сохраняя данные.
3. Выдайте нужные разрешения через настройки приложения. На компьютере используйте
   DEMO, на совместимом ГУ — режим реального подключения.
4. Для озвучки установите оригинальный
   [RuVoice 1.1.1](https://github.com/kost-t-human/ruvoice-tts/releases/tag/v1.1.1)
   и выберите голос в настройках навигации.

RuVoice устанавливается отдельно, не включён в APK Jeland OS и синтезирует речь
локально. Его [лицензия и авторство](app/src/main/assets/voice/ruvoice/NOTICE.txt)
регулируются отдельно.

Текущая линия сборок сохраняет прежнюю подпись для обновлений. Ключ не публикуется;
сборка с собственным ключом не установится поверх официальной без миграции.

## Карты и навигация

Карта, поиск и маршрутизация работают локально на MapLibre, Valhalla и Ferrostar.
Данные — OpenStreetMap. В APK включены:

- обзор дорог России: города и основные дороги, **без подробной адресной карты
  и дорожного графа всей страны**;
- подробная **тестовая зона Челябинск — Миасс — Златоуст**, а не полная область:
  карта, поиск и совместимый граф маршрутизации.

Регионы можно импортировать в формате `.jelandnav.zip` или скачать по прямой
HTTPS-ссылке на подготовленный пакет. Публичного каталога регионов пока нет.
Обычный `.osm.pbf` не заменяет готовый пакет. За границами дорожного графа
маршрутизация не гарантируется. Пробки и онлайн-перекрытия не подключены.

При ведении карта поворачивается по курсу автомобиля. «Карта на север» выбирается
отдельно; возврат к автомобилю восстанавливает режим «по ходу движения».
История и избранное хранятся на устройстве.

## Обновления

Приложение получает сведения из GitHub Releases, проверяет версию, размер,
SHA-256 и подпись APK, затем предлагает установку системным установщиком Android.
В релизе должны находиться APK и `jelandos-update.json`.

**Для обновлений с ГУ репозиторий и релиз должны быть публичными.** Пока репозиторий
приватный, используйте скачивание под своим аккаунтом и ручную установку.
Токен GitHub в приложение не встраивается.
[Подробности публикации](docs/GITHUB-UPDATES.md).

## Сборка из исходников

Нужны **JDK 21**, Android SDK Platform 36 и принятые лицензии Android SDK.
Gradle Wrapper включён в проект. Android Studio также может настроить окружение.

Укажите SDK через `ANDROID_SDK_ROOT` либо локальный `local.properties`:

```properties
sdk.dir=C\:/Android/Sdk
```

В Windows:

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest compileDebugAndroidTestKotlin
```

В Linux/macOS:

```sh
bash ./gradlew assembleDebug
```

Готовый debug APK: `app/build/outputs/apk/debug/app-debug.apk`.
Android-тесты запускаются отдельно на тестовом устройстве.
`assembleRelease` создаёт сборку, которую перед установкой нужно подписать;
секреты и ключи в репозиторий не включены.

Подготовленная тестовая карта и нативные библиотеки включены в исходники,
поэтому репозиторий заметно больше обычного Android-проекта. Неиспользуемые
модели Supertonic, APK, кэши и диагностические журналы в Git не публикуются.

## Участие в разработке

Каждый PR автоматически проверяется GitHub Actions: сборка, модульные тесты,
Android Lint и компиляция Android-тестов. Результат виден во вкладке Checks;
отчёты сохраняются в Actions. [Описание проверок](docs/CI.md).

1. Сделайте fork и отдельную ветку.
2. Опишите изменение; для функций ГУ укажите автомобиль и прошивку.
3. Проверьте затронутую функциональность и откройте Pull Request в `main`.
4. Решение о принятии принимает mrRadik. Слияние — через PR методом Squash.

Не добавляйте ключи, токены, персональные журналы и сторонние APK.
Убедитесь, что имеете право распространять свой вклад на предлагаемых условиях.
Для ошибки укажите версию Jeland OS, модель/прошивку, шаги повторения и ожидаемый
результат. Перед публикацией журнала удалите личные данные.
