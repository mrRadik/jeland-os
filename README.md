## Установка

Требуется Android 11 или новее. Разработка ведётся для штатного ГУ Desay Jeland J7;
другие модели требуют адаптации. Настройку выполняйте на стоянке.
APK устанавливается поверх предыдущей версии с сохранением данных.
Прошивка и штатная приборная панель не заменяются.

**Перед первой установкой разблокируйте и включите ADB на ГУ.**
Порядок действий описан в [инструкции по активации ADB](https://jconfig.app/tutorial?lang=ru)
в разделе «Шаг 3 — Активация ADB».

После активации скачайте ZIP-установщик Jeland OS, распакуйте целиком,
подключите ГУ USB-кабелем и запустите **install.cmd**.
Комплект содержит Jeland OS, RuVoice и ADB; нужные разрешения выдаются автоматически.
При первом запуске выберите язык, оформление по миниатюрам, разрешения,
автозапуск, карты и голос. Подключение к автомобилю выполняется автоматически.
Релизная сборка использует только реальные данные; DEMO доступен разработчикам в debug.

## Навигация и сценарии

Встроенный навигатор работает на **CoMaps**. Отдельное приложение CoMaps не нужно.
Обзорная карта мира входит в APK. Подробные регионы скачиваются из каталога
CoMaps внутри приложения; поиск, автомобильные маршруты и ведение по скачанным
регионам работают без интернета. Пробки и потоковая онлайн-карта не подключены.

Поиск, история и избранные точки доступны во вкладке «Навигация». Кнопка со
стрелкой включает слежение за автомобилем и поворот карты по ходу движения.
Главная страница и вкладка навигации используют один маршрут.
Для озвучки нужен RuVoice из установочного комплекта; синтез работает без сети.

- [Карты, поиск, слежение и голос](docs/COMAPS.md)

## Разработка

Нужны JDK 21, Python 3.11+, Android SDK Platform 36 и Build Tools 35.0.0.
Укажите SDK через `ANDROID_SDK_ROOT` или локальный `local.properties`.

```powershell
git submodule update --init third_party/comaps
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest lintDebug compileDebugAndroidTestKotlin
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
В Linux/macOS используйте `bash ./gradlew`.
Для обновления официальной версии нужен прежний ключ подписи; ключи в Git не входят.
Проверки на устройстве выполняются отдельно. [CI и правила PR](docs/CI.md).

Каждый может предложить изменение через fork и PR. Решение о включении принимает
владелец репозитория. Не публикуйте ключи, токены, чужие APK и персональные журналы.
