# 0.9.14 — контраст hero, адреса организаций, новая иконка

22.10.2026. versionCode 55, versionName 0.9.14-hero-search-icon.

## Изменения

- Светлая тема: единый плавный светлый градиент за верхней зоной hero (шапка, часы, дата, температура), начертание времени и температуры Medium. Цвет текста остаётся точным фоном противоположной темы. Отдельной карточки или фона у погоды нет. Фото, размеры и расположение блоков не менялись; ночь сохраняет свой прежний градиент.
- Поиск: отдельное необязательное поле address читается из индекса, участвует в поиске и выбранном назначении; под названием организации показывается город · улица и дом. Где исходных данных нет — «Адрес не указан», а не координаты или выдуманный ближайший дом. Точный адрес дома сохраняет приоритет при равном совпадении. Старые регионы без нового поля продолжают загружаться.
- Иконка: новый растровый автомобиль, подключённые Android adaptive/round ресурсы с безопасным отступом. Генерация встроенным image_gen, оригинал и полный промпт: [ICON-0.9.14.md](ICON-0.9.14.md).

Климат, приборка, QNX-чтение шин, музыка, команды камер и навигационный граф не изменялись.

## Адресные данные

Обработчик `tools/enrich-navigation-poi-addresses.py`, тесты `tools/test-poi-addresses.py`. Исходник — уже скачанный региональный OSM PBF, без сети/платного геокодера. Приоритет: явные теги той же POI-точки, уже существующий явный адрес в названии, затем адрес содержащего здание полигона. Ближайшее здание не используется; при конфликтующих адресах пересекающихся зданий адрес не назначается.

Из 13734 организаций адрес заполнен у 9696, у 4038 не найден. 1042 исходных адресных суффикса перенесены в поле address, 1037 явных адресов POI прочитаны из OSM, 8654 — из содержащих зданий (категории перекрываются). Все 214369 позиций, их координаты, типы и населённые пункты сохранены. Карта и граф побитно прежние. Полный отчёт: `navigation-data/chelyabinsk-west-poi-addresses/search-addresses-report.json`.

Индекс: 26969856 байт, меньше лимита 32 МиБ. Встроенный регион обновляется по manifest при запуске без повторной загрузки из сети. Пользовательские импортированные регионы автоматически не заменяются. Новый собранный пакет региона сохранён в `navigation-data/chelyabinsk-west-poi-addresses/region.jelandnav.zip`.
