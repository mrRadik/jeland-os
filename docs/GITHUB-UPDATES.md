# Обновления через GitHub

## Установка и очистка

В **Настройки → Обновление Jeland OS** проверьте версию, скачайте пакет и
на стоянке нажмите «Установить обновление». Подтвердите установку в Android.

Если установка не разрешена, выдайте разрешение Jeland OS в Android. Если
штатное окно разрешения недоступно, воспользуйтесь
[комплектным Windows-установщиком](https://github.com/mrRadik/jeland-os/releases/latest/download/JelandOS-Windows-Installer.zip).
Он выдаёт это разрешение Jeland OS при установке. Отдельный помощник не нужен.

После закрытия установщика без обновления APK сохраняется. Повторите установку
либо нажмите «Попробовать другой способ установки». Открытие окна не означает успех.

Кнопка **«Удалить скачанные APK»** удаляет кэш обновлений
Jeland OS и незавершённую загрузку. Неактивная попытка обновления отменяется.
Установленные приложения, карты и настройки сохраняются. Во время загрузки,
проверки и установки очистка недоступна.

Автопроверка работает при открытом приложении не чаще одного раза в 6 часов.
Автозагрузка допускается только по Wi-Fi без тарификации. Ручная загрузка
поддерживает Wi-Fi телефона; мобильный трафик требует подтверждения.
Установка начинается только по кнопке пользователя.

После успешного обновления установленные APK автоматически удаляются при
запуске новой версии. Новые, ещё не установленные обновления сохраняются.

Если кнопка «Установить» в системном окне не реагирует, включите
**«Альтернативный вариант установки»**. Подключить службу можно через
**enable-updates.cmd** из Windows-комплекта; меню Android для этого не требуется.

## Публикация выпуска

1. Увеличьте `versionCode`, задайте `versionName` и соберите APK.
2. Подпишите тем же ключом, что предыдущий выпуск. Ключи не публикуйте.
3. Назовите файл `JelandOS-<версия>.apk` и создайте метаданные:

```powershell
.\tools\New-GitHubUpdateManifest.ps1 -ApkPath <путь-к-APK>
```

4. Загрузите APK и `jelandos-update.json` в Assets одного публичного стабильного
   GitHub Release. Назначьте выпуск **latest**.
5. Проверьте установку поверх предыдущей версии и сохранение настроек.

Источник приложения — `mrRadik/jeland-os`. Проверяются размер, SHA-256, пакет,
версия, совместимость Android и подпись APK. Токен GitHub на ГУ не нужен.
Выпуски только с картами не назначайте latest: latest приложения должен содержать
APK и файл обновления.
