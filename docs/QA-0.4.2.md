# Jeland OS 0.4.2 — избранное на главной

## Изменения

- Крупные значки 56 dp вместо 36 dp, тот же нормализованный Drawable без искажения пропорций.
- В компактном блоке значок слева, название и действие справа. В высоких/узких карточках
  выбирается вертикальная компоновка. Геометрия разделов главной не изменена.
- Пустые слоты показывают плюс и «Добавить» / «Выбрать ярлык», без вымышленных приложений.
- Нажатие на назначенную карточку по-прежнему запускает приложение, пустая открывает
  существующую настройку избранного. Порядок и хранилище ярлыков не изменены.
- Сохранены сетка приложений 0.4.1, диапазон вентилятора до 10 и подключения Vehicle preview.

## Проверено 17.10.2026

- Сборка APK и test APK успешна; 46 unit-тестов, 0 ошибок.
- 7 экранных тестов на локальном BlueStacks / Android 11 / 127.0.0.1:5556, 0 ошибок.
- Размер 56×56 dp, настоящие значки BlueStacks/Chrome, две темы, открытие выбора
  через пустую карточку, четыре пустых слота, поиск и сохранение избранного.
- Главная без вертикальной прокрутки на 1440×1920, включая скрытие опциональных блоков.
- Сохранены тесты adaptive/vector/широких/высоких значков и управления вентилятором до 10.
- Снимки визуально проверены: screenshots/qa-0.4.2/favorites-dark.png,
  favorites-light.png, home-dark.png; настройки до/после тестов совпали побайтно.
