# 0.9.33 — шторка без прикладного ограничения по скорости

24.10.2026. versionCode 74, versionName 0.9.33-shade-automation.

## Изменение

Удалена проверка остановки как из LiveAutomationPlanner, так и перед SET
в DesayCarSession. Скорость больше вообще не принимается этими API;
проверку нельзя случайно сохранить в одном из двух слоёв. Удалён отдельный
секундный GET скорости, который обслуживал только эту проверку. Подписка
детектора события движения сохранена, как и фильтрация кэшированных пакетов.

Скорость/её отсутствие не блокирует ни шторку, ни соседние действия сценария.
Два события запуска (двигатель/движение) и ручной запуск сохранены. Подписи
на экране больше не требуют остановки и не ограничивают двигатель подогревами.

Не удалены проверки реальной связи, разрешённой записи, свежего состояния
самой шторки, признаков её собственного движения/недоступности, epoch/отмены
и запрет повторной отправки SET. OEM-команда и обратное чтение прежние.
