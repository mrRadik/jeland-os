# Jeland OS 0.4.3 — стабильная компоновка избранного

Причина различия со скриншотом 0.4.2: условие maxHeight >= 124 dp переключало
карточку в вертикальную компоновку даже при достаточной ширине. Это зависело
от высоты экрана и видимости других блоков главной. Теперь выбор зависит только
от доступной ширины: значок слева, название и действие справа. Узкий вертикальный
вариант сгруппирован по центру, без растягивания элементов по всей высоте.

Проверки 17.10.2026:

- Сборка APK / test APK, 46 unit-тестов — успешно.
- По 3 UI-теста на 1440×1920 и 1440×2160 в локальном BlueStacks Android 11:
  обе темы, размер иконки 56 dp, координаты названия справа от иконки,
  пустые слоты и открытие выбора, отсутствие прокрутки главной,
  комбинации видимости блоков шин/избранного — без ошибок.
- Предпочтения пользователя сохранены и восстановлены; JSON до/после совпадает.
- Разрешение эмулятора после проверки возвращено к исходному 1920×1080.
- На ГУ ничего не устанавливалось; Probe, климат и vehicle API не изменены.

Снимки: screenshots/qa-0.4.3/1440x1920 и 1440x2160.
Запрос 1440×2560 эмулятор ограничил высотой 2160, поэтому результаты указаны
по фактическому размеру приложения, не по запрошенному.
