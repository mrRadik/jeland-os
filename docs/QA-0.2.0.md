# Главная Jeland OS 0.2.0 — проверка 17.10.2026

## Объём этой итерации

После уточнения «пока только главный экран делаем» реализованы главная и её общие панели.
Отдельные экраны автомобиля/музыки/навигации/настроек не перерабатывались, работают прежние маршруты.
Кнопка «Приложения» открывает popup с поиском, запуском, реальными значками и настройкой избранного.
Никаких SDK навигации, реальных маршрутов или новых вызовов приборки.

## Готово

- Плотная адаптивная вертикальная композиция без пустого нижнего блока.
- Хедер JELAND + доступная связь Android + время; неизвестные уровни не выдумываются.
- Единая векторная сетка 24×24 / 1,55 для пиктограмм, без Emoji.
- Hero с правильным J7, погодой и топливом: остаток/до полного из 55 л, оценочный и неизвестный режимы.
- Музыка и mock-карта сохраняют прежние функции.
- Строгий top-down J7, несколько открытых дверей/капот/багажник, четыре независимых показания шин.
- Топология: перед слева; ПП сверху слева, ПЛ снизу слева, ЗП сверху справа, ЗЛ снизу справа.
- Демонстрационные пороги нормального/предупреждающего/критического/неизвестного давления редактируются и сохраняются.
- Глобальный overlay и предупреждение движения с открытым кузовом — только MOCK.
- Симметричный климат, уровни сидений, тёплый/холодный акценты, анимированная шторка, popup над климатом.
- Темы Dark/Light/Auto и сохранение. Избранное и его порядок сохраняются.
- Пакет ru.jeland.os, versionCode 3 / 0.2.0-mock. Предыдущие APK и исходники сохранены.

## Сборка и автоматизация

`clean assembleDebug testDebugUnitTest assembleDebugAndroidTest` и последующие сборки успешны.
Unit: **18 / 18**, ошибок и пропусков 0.
Instrumentation: **OK (7 tests)**, финальный прогон **34,946 с**.

Покрытие UI: прежние переходы, постоянный климат, изменение температур, сиденья 0–3,
темы, popup, поиск приложений, реальные кнопки избранного, реактивность дверей/шин,
правильное исчезновение overlay, неизвестные данные, отсутствие automotive/internet/overlay permissions.
Проверки избранного возвращают исходное состояние после временного тестового выбора.
При поиске предусмотрен adjustResize/imePadding. В BlueStacks текст вводился аппаратной клавиатурой,
экранная IME на сохранённом снимке не появлялась; её фактическое отображение отдельно не проверено.

Сначала автоматическая проверка останавливала установку на неопределённый serial emulator-5554.
Затем read-only проверкой доказано, что локальный порт 127.0.0.1:5556 принадлежит HD-Player PID 17188,
запущенному для тестирования экземпляру BlueStacks Rvc64. Только после этого туда установлены APK.
Модель Samsung в свойствах — профиль этого эмулятора, не физический телефон.

Временно использован 1440×1920, density не менялась. После прогона размер восстановлен до физического
1920×1080 / 240 dpi. На ГУ установка не выполнялась, Probe и ADB-коллектор не менялись.

## Артефакт

`artifacts/JelandOS-0.2.0-mock.apk`, debug, 29 522 584 байт.
SHA-256: `1A0A433BB6C6B84D2D1E62F7233AAD2638A3EEC6B1D9CFC349EE7C2A933A2DC0`.
Удалена неиспользуемая material-icons-extended; чистая пересборка уменьшила APK.
Это не performance-бенчмарк ГУ: FPS/потребление на автомобильном железе не измерялись.

Manifest добавляет только normal ACCESS_NETWORK_STATE и видимость MAIN/LAUNCHER.
Нет QUERY_ALL_PACKAGES, READ_PHONE_STATE, геолокации, INTERNET, SYSTEM_ALERT_WINDOW и android.car.*.
Первичные документы для решения по метаданным:
[Android package visibility](https://developer.android.com/training/package-visibility/declaring),
[NetworkCapabilities](https://developer.android.com/reference/android/net/NetworkCapabilities),
[TelephonyManager](https://developer.android.com/reference/android/telephony/TelephonyManager).

Изображение машины сверху создано встроенным imagegen, альфа сохранена; точный промпт и путь:
`docs/TOP-VIEW-ASSET.md`. Это художественная модель, не CAD/OEM-дамп.
