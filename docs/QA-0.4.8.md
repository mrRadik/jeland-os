# 0.4.8 — питание климата, шторка и чистый UI

## Климат

ClimateState.controlsEnabled требует известного включённого питания (HVAC/18).
При OFF/unknown недоступны температура обеих зон, вентилятор (±/шаги/ползунок),
три направления и остальные функциональные кнопки климата. Питание и закрытие/открытие
панели остаются доступны. Сиденья и другие независимые функции автомобиля не блокируются.

Контроль не ограничен цветом: disabled semantics и реальные pointer-обработчики;
ползуночный SetProgress возвращает false. MockClimateRepository отклоняет все
изменения кроме питания. Перед live SET сеанс проверяет свежий HVAC/18; unknown/OFF
блокирует HVAC-команды, кроме самого питания. Скрытого включения или повтора нет.

## Шторка

Локальный requestedShade обновляется при принятии команды, до Binder SET.
UI shadeUiPosition/shadeUiSummary использует этот выбор. RAW и reportedShade остаются
отдельной телеметрией, поэтому устаревший/противоречивый GET не срывает анимацию.
При ошибке отправки выбор откатывается; отказ по write-lock/busy не меняет картинку.
Значение не сохраняется как измеренное положение и не переживает разрыв live-сессии.

SET по-прежнему VR 0x50010/124, OPEN=1/CLOSE=2/HALF=3. GET — CAR 0x50001/10.
Никаких новых enum, STOP или обхода защит нет. По одному SET на принятую кнопку.
Readback шторки запланирован отдельно через 400/1200/2400 мс, не блокирует следующую
кнопку и не становится подтверждением достижения положения. Исходные значения,
SET_REQUEST/SET_RETURNED и SHADE_READBACK сохраняются в журнале.

## UI и журнал

Подробный lastCommand больше не транслируется в глобальное уведомление. RAW,
технические подписи и списки каналов убраны из рабочих панелей. Все данные остаются
в автоматическом журнале и ZIP. Для реальной ошибки/запрета есть короткий userMessage.
Предупреждения об открытом кузове сохранены. Никаких разрешений, выключения OEM-сервисов
или изменений таймеров скрытия штатного климата в этом выпуске нет.

## Проверка

Локально, только BlueStacks 127.0.0.1:5556. Автомобиль не подключался.
57 unit-тестов без ошибок: полная блокировка mock-мутаций, свежесть питания,
классификация независимых API и отделение представления шторки от её RAW.
Android-проверки включают disabled touch и slider semantics, повторное включение,
обе темы, вентилятор, настройки/экспорт, режимы потоков и основные рабочие экраны.
Дополнительно in-memory IVDBus: до/после Binder, повторные команды без ожидания GET,
устаревший feedback, rollback при RemoteException и запрет изменения без write-unlock.
Тестовый сеанс не связывается с OEM, не имеет реального vehicle Binder и не запускает
внешние сервисы. Команды записываются только в список FakeBus.

Финальный полный Android-прогон: 31 тест, 0 ошибок, 132.869 с.
Все 57 unit-тестов также успешны. Снимки Compose root: screenshots/qa-0.4.8,
включая climate-power-off.png. Экспорт ZIP отдельно проверен и сохранился рабочим.

При первом полном прогоне исправлены тестовые предположения: SET шторки использует
cmd124, а не cmd10; тесты интерфейса дожидаются портретного пересоздания Activity
после запуска на landscape BlueStacks. Основные проверки и ограничения не ослаблены.

APK: versionCode 15, JelandOS-0.4.8-controls-preview.apk. Старые версии сохранены.
На ГУ проверить выключение/включение питания, быстрый выбор OPEN/CLOSE/HALF,
затем START → L для журнала. Нельзя принимать локальную анимацию за датчик положения.
