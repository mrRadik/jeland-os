ароматизация /64 не меняются, OEM-приложение не останавливается.
Краткое исходное появление окна возможно; физическое скрытие требует теста в машине.

## SYNC — штатный протокол, не клиентская подмена

Источники: HvacID.ID_AC_DUAL_MODE=3; HvacModel.k()/P();
HvacPageView.i(int) / onSyncStatus в декомпилированном штатном SVHvac.
GET /3=0 означает SYNC включён, GET /3=1 — независимые зоны.
SET /3=[1] включает SYNC, SET /3=[2] отключает.
OS отправляет только выбранную команду и читает /3, /10, /13; не копирует
вторую температуру отдельным SET и не рисует успех до обратного чтения.
Неизвестный/устаревший /3 блокирует кнопку. Это восстановлено по OEM-коду;
первое подтверждение на этой машине ещё необходимо.

## Температурный ползунок

Открывается нажатием на число водителя или пассажира в нижней панели.
Компактное окно расположено над панелью, остальной экран не перестроен.
В ГУ диапазон LO, 16–30, HI, шаг 1: raw 0–16 по формуле raw=уставка−15,
где крайние 15/31 — только внутреннее представление LO/HI, не обещание 15/31 °C.
Driver HVAC /10; passenger /13. В DEMO диапазон 16–32 с прежним шагом 0.5.
Перетаскивание меняет предварительный выбор; отпускание отправляет один SET,
отмена — ни одного. Питание OFF/неизвестно, stale, busy, нет подключения или
запись заблокирована — команд нет. LO/HI и неизвестное состояние сохраняются.

## Проверка на стоянке

1. START → 1 → JelandOS-0.6.7-climate-slider.apk. Обновить поверх старой версии.
2. Подключить ГУ и разрешить команды. При включённом климате нажать число
   водителя, выбрать температуру и отпустить; затем проверить пассажирскую зону.
3. В меню климата включить SYNC, изменить водительскую температуру, сверить обе
   зоны со штатными показаниями. Выключить SYNC и проверить независимую регулировку.
4. По одной команде проверить температуру, вентилятор, AUTO; после каждой ждать
   4–5 секунд. Отметить, исчезает ли штатное окно и не появляется ли снова.
5. При выключенном питании остальные климатические команды должны блокироваться.
6. START → L: сохранить журнал с SET/GET /3, /10, /13, /9,
   HVAC_UI_DISPLAY_CLEAR и HVAC_UI_WINDOW_CLOSE либо его ошибкой.

Температуры шин, наружный датчик и CarPlay этой доработкой не объявляются решёнными.
