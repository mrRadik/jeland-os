# Автоматизации

Создайте сценарий, задайте название и добавьте устройства. Повторное нажатие
на выбранное устройство убирает его из сценария. Для каждого устройства
выберите собственное действие.

Доступны четыре отдельных сиденья, подогрев руля и панорамная шторка.
Передние сиденья поддерживают подогрев и вентиляцию, задние — подогрев.
Подогрев и вентиляция одного сиденья одновременно не включаются.

## Запуск

- **Вручную** — кнопкой на карточке сценария.
- **По температуре** — ниже или выше порога при выбранном событии.
- **Автоматически без температурного условия** — при выбранном событии.

Событие выбирается для каждого автоматического сценария:

- **При запуске двигателя** — после подтверждения его работы, без ожидания движения.
- **После начала движения** — после подтверждённого устойчивого движения.

Открытие приложения и пробуждение экрана сами по себе не являются началом поездки.
Если нет подтверждения события или свежей температуры, зависящий от них сценарий
пропускается. Порог проверяется строго: «ниже 5» означает меньше 5 °C.

Карточка показывает устройства, действия и условия. Тумблер включает или
отключает автоматический запуск и не меняет порядок списка. Ручной запуск
сохраняет проверки связи и доступности команд.

В DEMO команды автомобилю не отправляются. Для реальной работы нужны совместимый
ГУ, подключение к автомобилю и поступающие данные. Новые сценарии проверяйте на стоянке.
