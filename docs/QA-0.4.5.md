# Jeland OS 0.4.5 / Probe 0.7 — сохранение логов и заметная метка

18 октября 2026. Сборки проверялись только в локальном BlueStacks 127.0.0.1:5556.

- Журнал OS теперь создаётся с SESSION_BEGIN при запуске приложения и содержит
  версию, SDK, режим, resume/pause, изменения режима, GET/EVENT/SET/ошибки.
- Экспорт вручную из Настроек в MediaStore.Downloads, папка Download/JelandOS.
  ZIP содержит diagnostics.json с версией/режимом/кешированным RAW и журналы приложения.
  Сетевые вызовы, GET/SET, logcat, чужие файлы и настройки пользователя не собираются.
  Бюджет 32 MiB, сначала новые журналы. Усечения/пропуски отмечены явно; оригиналы остаются.
  Файл публикуется после завершения ZIP; при ошибке удаляется только свой недописанный экспорт.
  Общий доступ выдаётся выбранному пользователем приложению через системный chooser.
- 49 unit-тестов и 4 UI-теста успешно: реальный ZIP в Загрузках без storage permission,
  читаемое содержимое, отсутствие новых подключений/команд при экспорте, главная без
  прокрутки, постоянная климат-панель и диапазон fan10. Тестовый публичный ZIP удалён
  тестом; журналы сохранены. Результат/образец ZIP: screenshots/qa-0.4.5.
- Preferences до/после совпали побайтно; размер эмулятора возвращён к 1920×1080.
- Сборщик START → L выгружает также Download/JelandOS, валидирует структуру ZIP,
  отмечает число валидных сохранений отдельно. 27 fixture-тестов Toolkit прошли.
  Дополнительно реальный локальный прогон сборщика распознал экспорт OS.
- Probe 0.7: метка 720×120, верх по центру с отступом 140 физических пикселей,
  шрифт 46/27 px, контрастный фон/контур, без мигания; автоудаление через 8 секунд.
  Не полноэкранная, не фокусируемая, не перехватывает касания и не затемняет фон.
  Фильтр display2/1920×720, ручное подтверждение стоянки и закрытие на ГУ сохранены.
- Локальный приватный VirtualDisplay: onDraw, PixelCopy, 8-секундный таймер,
  ручное закрытие и атрибуты окна прошли; 800 проверок mock Binder/Parcel успешны.
  Скрипт C ждёт завершения 8-секундного теста до снимков «после».

Не утверждается, что метка видна на реальной приборке: Android screenshot подтверждает
Android-композицию, а не физический маршрут. Даже маленькое окно может переключить
целый видеослой — тест только на стоянке, со свободной возможностью немедленно закрыть.
