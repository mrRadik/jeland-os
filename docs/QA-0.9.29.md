## Известная граница

Вся исполнительная часть автоматизаций остаётся MOCK. Детектор живой поездки
пока read-only, не подключён к исполнителю. Реальные автоматические команды
этим релизом не включены. Автоматические режимы проверяются явной тестовой
сессией; физическое выполнение на ГУ не заявляется. Ни открытие приложения,
ни запуск двигателя сами по себе не запускают сценарии.
