# 0.9.10 — светлый hero и тематические цвета

Дата: 2026-10-21. versionCode 51, versionName 0.9.10-light-hero.

## Изменения

- Добавлен новый локальный ресурс hero_jeland_light.png, сгенерированный встроенным image_gen
  по исходному hero. Сохранены J7, чёрный цвет, ракурс и композиция; фон — светлый зимний день в горах.
- Ночной hero_jeland.png не изменён. Hero выбирает картинку по UiState.dark,
  то есть и для принудительной темы, и для AUTO с реальным штатным day/night signal.
- В дневном hero нет тёмного scrim/боковой градиентной дымки. Только нижние 8% переходят в фон.
- Цвет времени/даты/температуры и текста шапки над hero равен фону противоположной темы:
  DARK → #E9F0F5, LIGHT → #030B12. Активные индикаторы мобильной связи, Wi-Fi и Bluetooth того же цвета;
  неактивные — тот же RGB с пониженной прозрачностью. Данные и семантика подключения не менялись.
- ArtText/ArtMuted не инвертированы глобально: обложки музыки, карта и другие тёмные иллюстрации сохранены.
- Компоновка, высоты hero/панелей, климат и управление автомобилем не менялись.

- 178 JVM-тестов, 0 failures, 0 errors, 0 skipped. Четыре новых теста проверяют
  точное соответствие противоположному фону, два разных ресурса/обратный переход,
  цвет и прозрачность активных/неактивных индикаторов, неизменность artText других иллюстраций.

- Сам сгенерированный ресурс визуально осмотрен: чёрный J7 сохранён, светлый дневной фон,
  свободное небо для текста, без рамок/интерфейса и тёмной виньетки.
