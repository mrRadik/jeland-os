20 октября 2026, versionCode 39. Изменения в основной рабочей копии,
HEAD refs/heads/main; отдельная ветка, коммит или переключение не создавались.
Ранее незакоммиченные изменения сохранены.

## Что реализовано

- Выбор установленного 2ГИС / Яндекс Навигатора, версия/доступность пакета,
  сохранение выбора. Автоматической смены навигатора нет.
- Запуск через PackageManager, без привязки к внутреннему классу Activity.
- Сохранение до 12 точек (включая Домой / На работу), изменение и удаление.
  Ввод — широта, долгота в градусах с десятичной точкой. Неверные диапазоны,
  NaN и бесконечности не принимаются. Поиск адресов — в самом навигаторе.
- Явные ACTION_VIEW ссылки только выбранному пакету. Текущую геопозицию,
  поиск, офлайн-карты, маршрутизацию, озвучку и ведение выполняет навигатор.
- NotificationListenerService: пользователь включает доступ в настройках
  Android. Только два разрешённых пакета, их навигационные уведомления;
  остальные отсекаются до чтения extras. Удаление уведомления, отключение
  службы, смена провайдера, отзыв доступа не оставляют чужой манёвр на экране.
- Виджет главной показывает доступный текст без выдуманных расстояний,
  ETA и направлений. Демонстрационная карта не используется в основном
  графе зависимостей, в том числе при DEMO автомобиля.
- Диагностика NAV_PROVIDER / NAV_LAUNCH / NAV_NOTICE в журнале OS, доступном
  через START → L. Нет координат, названий мест или текста уведомления в логе.

Новых uses-permission нет. Служба защищена BIND_NOTIFICATION_LISTENER_SERVICE;
это разрешение для Android при подключении службы, не привилегия нашего APK.
Android показывает общий доступ к уведомлениям: экран объясняет этот охват,
хотя код обрабатывает только два навигатора. Данные подсказок только в памяти.
Нет сети/сервера/платного SDK, фоновых загрузок карт, доступа к аккаунтам,
модификации APK навигаторов, root или изменений OEM/VDS.

## Ограничение карты и CarPlay-референс

Это не полная CarPlay-проекция и не встроенный SDK. Кнопки, выбор приложения,
избранные места и карточка инструкции — первый рабочий шаг интеграции.
При открытии навигатора карта отдельным окном; панель климата Jeland OS
поверх него не остаётся. Рисованная карта не выдаётся за реальную.

Официальное Activity Embedding поддерживается в основном с Android 12L/API32;
межприложное встраивание требует согласия целевого приложения. Произвольное
ActivityView/TaskView обычному APK Android11 не обещается. Привилегированный
OEM-хост или согласованный SDK — отдельное исследование, не выполненная часть.
Устройство не переводилось в root/priv-app, скрытые права не выдавались.

Оба приложения публикуют не обязательно все манёвры через Notification.
При недоступности нет имитации стрелок. Подключение службы не объявляется
активным ведением маршрута. Из текста не выводятся полоса/скорость/дистанция.
Вызовы Яндекса по координатам могут ограничиваться без идентификации
разработчика; ключи/подписи не придумываются. Обычный запуск доступен отдельно.

## Проверка на стоянке

1. START → 1 → JelandOS-0.8.0-navigation.apk. Навигаторы должны быть установлены.
2. Навигация → выбрать 2ГИС или Яндекс. Проверить версию и доступность кнопки.
3. «Открыть» → пройти первый запуск выбранного навигатора. Разрешить ему GPS,
   настроить офлайн-карты самостоятельно через Wi-Fi. В аккаунт входить только
   по своему желанию. Jeland OS не получает пароль или доступ к аккаунту.
4. Вернуться в Jeland OS → «Разрешить подсказки» → включить именно службу
   «Jeland OS — подсказки навигации». Разрешение необязательно для запуска карт.
5. Построить маршрут в навигаторе. Вернуться в Jeland OS: сравнить текст
   карточки с уведомлением самого навигатора. Не проверять во время управления.
6. Завершить маршрут в навигаторе: подсказка должна исчезнуть при удалении
   уведомления. Переключить провайдер: чужая подсказка не должна остаться.
7. Задать «Домой» координатами известной точки. Проверить передачу назначения
   обоим приложениям и восстановление выбора после перезапуска Jeland OS.
8. После проверки START → L. Сообщить, какой навигатор, что видно в его
   уведомлении и в карточке. Для дальнейшего разбора нужен лог NAV_*.
