# 0.9.12 — чтение температур шин из QNX

22.10.2026. versionCode 53, versionName 0.9.12-tyre-temperature.

## Область изменений

Добавлены QnxTyreTemperatureDecoder/Cache, ограниченный read-only QnxTyreReadProtocol и foreground reader. Интеграция в LiveVehicleReducer и жизненный цикл DesayCarSession. Существующие UI колёс получают температуру независимо от давления; текст пояснения обновлён. Меню, климат, музыка, навигация, hero и темы не перестраивались.

Подробные доказательства, ограничения и исследование аварийки: [TYRES-AND-HAZARD-FIRMWARE-20261022.md](TYRES-AND-HAZARD-FIRMWARE-20261022.md).

## Как проверить

Готовая APK: `artifacts/JelandOS-0.9.12-tyre-temperature.apk`, 470126312 байт. Подпись APK Signature Scheme v2 проверена. SHA-256: `2A816813572DEFAE520607CF8D413BFADF3B7398BF2A7F4EDA78A3792EFF0470`. Финальный повтор сборки и всех 188 JVM-тестов успешен.

На стоянке установить новую Jeland OS через START → 1. Включить режим ГУ, остаться на главном экране 10–20 секунд. Открыть каждое колесо и сопоставить со штатной приборкой. Если прочерки — это отказ/неподдержанный формат, не повод включать debug или менять права. Сразу собрать START → L: важны строки `TPMS_QNX`, `TPMS_QNX_SAMPLE`, `TPMS_QNX_UNAVAILABLE` в журнале OS. Сохранить показания четырёх штатных температур для сравнения.
