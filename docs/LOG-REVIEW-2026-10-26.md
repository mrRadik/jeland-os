## Обновление

- Активная сеть 138 — подключённый Wi-Fi с INTERNET и VALIDATED,
  но без NOT_METERED. Это точка доступа телефона. Старая проверка требовала
  NOT_METERED даже по ручной кнопке и отклоняла её до начала скачивания.
- После разрешения мобильной загрузки есть UPDATE_READY version=76:
  размер, SHA-256, пакет, версия и подпись прошли проверку.
- В старой версии нет записей вызова и результата установки. По этому
  журналу нельзя установить, открылось ли разрешение или системный установщик.

Изменения:

- Ручная загрузка по Wi-Fi принимает в том числе тарифицируемые точки доступа.
  Автоматическая загрузка по-прежнему допускается только без тарификации.
- Соединение и перенаправления привязаны к выбранной Android-сети;
  при её потере нет незаметного переключения на SIM.
- После прежних проверок APK создаётся сессия PackageInstaller с системным
  подтверждением. Закрытый receiver принимает результат и пишет его в журнал.
  Отмена, запрет, нехватка места, конфликт, неверный APK и отсутствие ответа
  отображаются в настройках; файл сохраняется для повторной попытки.
- В diagnostics.json добавлены разрешение установки, ID сессии, результат
  и версия скачанного обновления. APK других приложений в экспорт не добавляются.
- Добавлена повторная загрузка APK.

а тумблер обновлял это поле. Список теперь сортируется по приоритету,
дате создания и ID. Дата редактирования сохраняется; алгоритм исполнения
и разрешение конфликтов действий не менялись.

Чтение шин не объявляется исправленным; неизвестная температура не заменяется
