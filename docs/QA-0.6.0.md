# Проверка 0.6.0 — автоматизации

Версия 0.6.0-automations-preview, versionCode 18, пакет ru.jeland.os.
Новый проект не создавался; Probe и реальные OEM-команды не менялись.

77 unit-тестов успешны (17 новых по автоматизациям): строгие температурные
условия, неизвестное/просроченное/будущее/NaN измерение, валидация, KEEP/OFF,
четыре независимых места, конфликт текущего нагрева с KEEP вентиляции,
приоритет и стабильная развязка равенства, изоляция правил, ошибки исполнителя,
однократное исполнение несколькими движками, ручные изменения и неизменяемый
снимок правила при параллельном редактировании.

В BlueStacks 127.0.0.1:5556 новые 6 Room-проверок и 3 UI-проверки проходят.
Room: типизированный roundtrip, независимое редактирование/переключение/удаление,
rollback невалидной записи, запрет воскрешения удалённого правила, закрытие и
повторное открытие дисковой базы, сохранённый указатель сессии, PENDING после
имитированного прерывания, атомарный claim несколькими репозиториями.
Дисковые QA-базы создаются с уникальным qa-automations-UUID.db и удаляются после
проверки. Пользовательская база не очищается.

UI: создание/сохранение/изменение/включение-выключение/отмена/подтверждение удаления,
сохранение другого правила, все четыре места одним объектом, отсутствие задней
вентиляции в модели, автосброс конфликтующего переднего режима в OFF,
только два положения шторки без температуры, ручная сессия, отсутствие повторов,
безопасность шторки в движении, отсутствие изменений обычных репозиториев
сидений/автомобиля, восстановление Bundle черновика через SavedStateHandle.
UI использует отдельную in-memory Room и MemorySettingsStore.

Снимки screenshots/qa-0.6.0/: empty-dark, rules-dark/light, seats-editor-front-dark,
seats-editor-rear-dark, seats-editor-auto-day/auto-night, shade-editor-dark/light,
delete-light, debug-unsafe-light. Снимок диалога — самого диалога, остальные —
всей Compose-поверхности. Проверены читаемость, цельная подпись в левом меню,
неизменные хедер/климат и отсутствие перекрытия кнопок.

Полный регрессионный прогон на итоговом APK: 48/48 Android-проверок успешны,
142.026 с. Включены существующие климат, шторка, приложения, журналирование,
индикаторы, темы, главная без прокрутки и интерфейс остальных экранов.
Слушатель QaPreferenceGuard сохранил/восстановил настройки локального стенда.
Только локальный Android. Никакого доказательства реальной автомобильной
автоматизации эти тесты не дают — её нет в этой версии по условию задачи.

Сборка использует KAPT Kotlin 2.0.21 и Room 2.7.2. KAPT предупреждает о fallback
языка генерации stubs на 1.9; генерация Room, APK и тестов проходит, схема
app/schemas/ru.jeland.os.data.automation.AutomationDatabase/1.json создана.
Манифест и набор runtime-разрешений не расширялись.
