## Изменения

- Вместо текстового поля температурного порога — существующий нативный
  JelandSlider с холодно-тёплым градиентом, диапазоном −60…+60 °C,
  округлением к 1 °C, знаковым значением и кнопками точной подстройки.
  На границах соответствующая кнопка недоступна. Порог сохраняется в Room;
  «Ниже»/«Выше» не меняет выбранную температуру. Клавиатура для порога не нужна.
- Включена ранее подготовленная правка выбора устройств: второй клик убирает
  устройство/его действия, третий снова добавляет. Прочие действия сохраняются.
- Включён подготовленный механизм GitHub Releases: проверка, Wi-Fi-загрузка,
  проверки APK/подписи и системная установка только с подтверждением.
  artifacts/jelandos-update.json сформирован по настоящему новому APK;
  копия также в portable. Ничего на GitHub не публиковалось.

## Границы

не подключён к исполнительным командам. Слайдер не включает реальную автоматику.

APK + jelandos-update.json и более высоким versionCode; полевой путь установки
из GitHub на ГУ не проверен. Лицензия проекта остаётся неутверждённым черновиком,
не встроена и не опубликована. Изменений удалённого репозитория/PR/настроек нет.
