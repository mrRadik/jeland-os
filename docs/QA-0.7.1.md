# Jeland OS 0.7.1-dashboard

Дата: 20 октября 2026. versionCode30. SHA256 APK:
`0EA3A80D5EC15C728B8F7291407F9DFDC6F6D79293BD5FECF3BF6A5E54A522F7`.

## Главный экран

Пропорции пересмотрены по последнему референсу пользователя, который отменил
слишком высокий первый вариант. Hero без рамки, с градиентным переходом к фону.
Навигация слева, музыка справа; состояние автомобиля около22% рабочей высоты,
а не48%. Затем быстрые действия и избранное (пять компактных ячеек).
Машина горизонтальна и центрирована внутри своей схемы, геометрия дверей и
hit targets используют тот же fitted rectangle. Виджет топлива перенесён
между задними колёсами (справа при существующем направлении машины носом влево),
сохраняет открытие панели топлива. Popup и показания колёс интерактивны.
Климатическая панель высотой122dp с нижним отступом18dp, кнопки56–64dp вместо48–52.
Нет прокрутки главной; боковое меню и отдельные разделы сохранены.

## Живые данные и команды

Погода использует прежний наружный датчик без сетевого запроса: последнее
корректное значение сохраняется при короткой потере/обновлении до10минут,
после этого снова UNKNOWN. При переходе в DEMO кэш сбрасывается. Тап открывает
штатную погоду. Это не загрузка прогноза и не новая формула температуры.

Bluetooth по-прежнему окрашивается акцентным голубым при подтверждённом
подключении. Дополнительно свежий OEM BT music sample используется как источник
состояния A2DP, если Android radio API не отражает отдельный модуль ГУ.
Наличие трека CarPlay/USB само по себе не делает Bluetooth подключённым.
При других источниках остаётся наблюдение Android BT-профилей. На ГУ проверить.

Ручной checkbox разрешения обычных команд удалён. Запись автоматически доступна
при подключённой ГУ в активном приложении. На pause/disconnect команды по-прежнему
не отправляются, сохранённые состояния не воспроизводятся автоматически.
Проверки свежести, питания климата, диапазонов и allowlist команд сохранены.

Убраны Thread.sleep400/800/1200 и блокировка всей очереди до readback. SET идут
последовательно в прежнем single executor, без искусственной паузы. GET проверки
через400/1200/2400мс вынесены в фон; устаревшие серии пропускаются при новой команде.
Нет повторов SET. Краткая CommandProjection хранит ожидаемое значение2,5с для
серии относительных тапов (например6→7→8), отдельно от measured VDS reducer.
Проекция очищается на disconnect и не считается показанием автомобиля.
Физическая обработка команды блоком автомобиля может занимать время.
