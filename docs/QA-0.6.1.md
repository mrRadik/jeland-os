# Проверка 0.6.1 — климат и шторка

Пакет ru.jeland.os, versionCode 19, versionName 0.6.1-ui-polish.

## Изменения

- Отдельный «Обдув лобового» возвращён в popup и постоянную панель: прежний
  ClimateRepository.toggleDefrost(), HVAC 0x5000A/24, без изменения wire-format.
  Обогрев лобового /65 и направления /6 остаются независимыми функциями.
- Активное состояние берётся из defrost с проверкой known(24). Питание должно
  быть известно и включено. Поведение остальных команд и разрешение записи
  не изменены. При восстановлении питания нет автоматического повтора нажатий.
- Окно шторки использует существующий vehicle_top.png. Анимированное полотно
  совмещено с проёмом крыши; при открытии его левая граница движется вправо.
  CLOSED: полотно закрывает весь проём; HALF: правая половина; OPEN: полотна нет.
  Неизвестное положение не подменяется HALF. Команды и модель requestedShade
  сохранены, физическое положение по одной анимации не подтверждается.
- Нижний dock: RoundedCornerShape(26.dp) для всех четырёх углов, внешний отступ
  внутри прежней высоты. Остальные блоки главной не перестраивались.
- Подпись рециркуляции уменьшена для новой строки из восьми кнопок, без разрыва слова.

## Проверки

78 unit-тестов проходят, включая монотонное движение полотна слева направо,
все три положения, неизвестное положение и ограничение диапазона.
Повторный общий прогон: OK (51 tests), 0 ошибок, BlueStacks / Android 11.
UI-тесты проверяют независимость обдува от обогрева, общую блокировку питания,
рабочие кнопки popup шторки, выделение команды, анимацию и неизвестное положение.
Снимки: screenshots/qa-0.6.1/, тёмная и светлая темы.

При первом общем прогоне два старых изолированных теста климата потеряли
подменённый интерфейс из-за пересоздания Activity при повороте BlueStacks.
В подготовку тестов добавлено ожидание portrait, как в других UI-тестах проекта.
Изменений жизненного цикла приложения для этого не потребовалось.

Все проверки выполняются в локальном BlueStacks 127.0.0.1:5556, в DEMO либо
с фиктивным портом OEM. Физическая ГУ не использовалась. Автоматизации остаются
MOCK-only, код Probe не менялся в этой доработке.

## Проверка на ГУ

На стоящем автомобиле открыть климат: «Обдув лобового» должен управлять прежней
функцией /24; кнопка «Обогрев лобового» /65 остаётся отдельной. Проверить оба
места управления и блокировку обдува при выключенном питании климата.
Открыть шторку, выбрать закрыта / наполовину / открыта. Полотно в UI уходит вправо,
выбранная команда отражается сразу; ожидание OEM feedback не возвращено.
Дополнительных действий, автоматических команд или управления автомобилем при
установке новой версии не добавлено.
