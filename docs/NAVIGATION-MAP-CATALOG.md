# Скачать карты

Откройте **Настройки → Навигация → Скачать карты** или шестерёнку на карте.
Укажите «Путь до карт», выберите регион и нажмите «Скачать». После проверки
пакет установится. При активном маршруте потребуется подтвердить его завершение.

Установленную карту можно удалить кнопкой «Удалить». Подробный регион и обзор
России удаляются отдельно; настройки и остальные карты сохраняются.

Обзор содержит крупные дороги и города. Для адресов и маршрутов нужен подробный
регион с дорожным графом. За его границами маршрутизация не гарантируется.

Wi-Fi телефона поддерживается; для мобильной сети нужно подтверждение.
После завершения процесса загрузка восстановится при следующем запуске приложения,
а при поддержке сервера продолжится с места обрыва. Ошибочный пакет не заменяет
рабочую карту.

## GitHub

Стандартный источник: `https://github.com/mrRadik/jeland-os/releases`.
Можно указать другой репозиторий, Releases или конкретный выпуск.
Пустое поле возвращает стандартный источник.

Загрузите `.jelandnav.zip` или `.pmtiles` в Assets публичного стабильного релиза.
Новый пакет можно разместить отдельным релизом, не меняя старый. При одинаковом
имени файла выбирается свежая публикация. Название задаётся подписью файла,
контрольная сумма берётся из GitHub. APK, черновики и предварительные релизы
не показываются. Релиз только с картами не назначайте latest приложения.

## Свой сервер

Укажите HTTPS-папку с `maps.json` или ссылку непосредственно на JSON:

```json
{
  "format": 1,
  "maps": [{
    "id": "region-id",
    "title": "Название региона",
    "kind": "region",
    "url": "region.jelandnav.zip",
    "bytes": 67088426,
    "sha256": "64 шестнадцатеричных символа"
  }]
}
```

`url` — HTTPS-ссылка или путь относительно каталога. `kind` — `region` для
навигационного пакета или `overview` для обзорного PMTiles Protomaps v4.
`sha256` необязателен, но указанная сумма должна совпасть с файлом.
Максимальный пакет — 512 МиБ, каталог — 2 МиБ и 500 записей.

Создать пакет из OpenStreetMap поможет [Jeland Map Builder](MAP-BUILDER.md).
Обычный `.osm.pbf` или произвольный ZIP нельзя установить вместо готового региона.
