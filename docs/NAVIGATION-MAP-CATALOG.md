# Каталог офлайн-карт

В настройках приложения: Навигация → «Путь до карт» → «Скачать карты».
На вкладке навигации: шестерёнка → «Скачать карты». Поле «Путь до карт»
также расположено прямо над списком в этом окне. Прежнее название
«Офлайн-карты» заменено во всех переходах и заголовках.
Источник по умолчанию — `https://github.com/mrRadik/jeland-os/releases`.
Пустое поле также означает стандартный источник. Ввод сохраняется между запусками.
Список открывается отдельно; у карты показаны название, размер и действие.
После изменения пути список можно обновить круглой кнопкой или нажатием
«Готово» на клавиатуре; повторная загрузка самого пакета при этом не начинается.

## Источники

Для GitHub можно указать репозиторий, страницу Releases или конкретный релиз.
Без токенов и учётной записи приложение читает опубликованные релизы через REST API.
Из последних 100 релизов выбираются загруженные `.jelandnav.zip` и `.pmtiles`;
черновики, предварительные релизы, APK и прочие файлы не показываются.
Для одинакового имени файла выбирается самая свежая публикация.
Название берётся из label файла релиза, SHA-256 — из digest GitHub.
Сам пакет скачивается по постоянной browser_download_url, не по временной
подписанной ссылке, полученной на этапе проверки размера.

Для другого сервера: HTTPS-ссылка на JSON-каталог или на папку с `maps.json`.
Каталог имеет вид:

```json
{
  "format": 1,
  "maps": [
    {
      "id": "region-id-from-package-manifest",
      "title": "Название региона",
      "kind": "region",
      "url": "region.jelandnav.zip",
      "bytes": 67088426,
      "sha256": "64 hexadecimal characters"
    }
  ]
}
```

`url` может быть абсолютным HTTPS-адресом или путём относительно JSON-каталога.
`kind`: `region` — совместимый пакет с картой, поиском и Valhalla-графом;
`overview` — обзорный PMTiles Protomaps v4. `sha256` необязателен, но если указан,
должен содержать 64 шестнадцатеричных символа и совпасть с загруженным файлом.
Имена файлов, состав ZIP, внутренние контрольные суммы и схема PMTiles
по-прежнему проверяются установщиком; каталог не делает произвольный архив совместимым.

## Загрузка и установка

Нажатие «Скачать» разрешает загрузку и установку выбранной карты.
По Wi-Fi, включая точку доступа телефона с тарифицируемой сетью, загрузка разрешена.
Для тарифицируемого подключения без Wi-Fi запрашивается подтверждение размера.
На обычном Android передача выполняется системным DownloadManager и переживает закрытие приложения.
Если в прошивке ГУ отсутствует его провайдер (`Unknown URL content://downloads/my_downloads`),
приложение автоматически переключается на собственную HTTPS-загрузку.
Она использует разрешённую сеть, проверяет размер и SHA-256 и сохраняет частичный файл.
После остановки процесса передача возобновляется при следующем запуске Jeland OS;
докачка используется, если сервер поддерживает диапазоны и неизменность файла подтверждена ETag.
После первой ошибки недоступный системный сервис повторно не вызывается.
Сохраняются источник, название, checksum и запрос автоматической установки.
После проверки файла он устанавливается автоматически, если нет активного маршрута.
Если маршрут активен или ещё строится, появляется «Установить» с подтверждением его завершения.
Ошибка проверки не заменяет установленную карту. После установки скачанный
временный пакет удаляется, установленная карта остаётся в собственном хранилище.
Одновременно активен один подробный регион, как и до этого изменения.
Отметка обзорной карты из каталога сохраняется после перезапуска приложения.

У установленной карты есть «Удалить». После подтверждения удаляются локальные
файлы; для подробного региона сначала освобождается движок и завершается маршрут.
Удаление работает и без доступного каталога: установленные карты показываются
отдельными строками при отсутствии соответствующих записей источника.
После удаления снова доступно скачивание. Флаг удаления сохраняется: bundled
данные не распаковываются заново при перезапуске. Неизменяемые исходные assets
внутри установленного APK остаются частью APK; удаляются рабочие копии в хранилище.
При удалении региона карта продолжает показывать обзор России, если он установлен.
Обзор можно удалить отдельно. Повторная проверенная установка снимает флаг удаления.

Кнопка и блок поддержки убраны из настроек приложения; README не изменён этой правкой.

Ограничения: один файл до 512 МиБ, каталог до 2 МиБ и 500 записей.
Каталог запрашивается при открытии списка, а не при каждом запуске приложения.
Неудачное обновление списка оставляет уже полученные записи в текущей сессии.

## Подготовленные пакеты

`tools/publish-navigation-maps.py` проверяет архив против текущего bundled manifest,
подготавливает `artifacts/maps/maps.json`, подробный регион и обзор России.
`--publish` публикует только эти данные отдельным релизом `maps-2026-10-26`,
не меняя APK, update manifest или исходники в GitHub. Существующие публичные
файлы не перезаписываются; новая публикация не назначается latest.

Доступные исходные данные: тестовая зона Челябинск—Миасс—Златоуст и обзор
крупных дорог/городов России. Это не подробная навигационная карта всей России.
Атрибуция OSM/Geofabrik остаётся на самой карте и в описании пакетов.
