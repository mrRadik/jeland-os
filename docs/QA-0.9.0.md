# Jeland OS 0.9.0 — собственная полноразмерная офлайн-навигация

Основная ветка main; ru.jeland.os, versionCode 41. Не полный аналог Яндекс/2ГИС.
Чужие APK не встраиваются и ADB-host не запускается. Старые исходники host/companion
сохранены для исследования, но не являются текущей вкладкой.

## Реализация

- Нативный MapLibre 13.7.1, явно OpenGL ES backend; TextureView внутри Compose.
- Карта заполняет всю вкладку без вертикального скролла. Контрастные панели
  поиска/манёвра/маршрута поверх неё; кнопки масштаба, позиции, обзора и настроек.
- Светлая/тёмная карта следует теме OS. Курсор позиции, пункт назначения,
  контрастная линия маршрута с обводкой. Камера сохраняется при смене вкладок.
- Один application-scoped OfflineNavigationRepository для вкладки и мини-карты.
  На главной используется сохранённый снимок настоящей карты из памяти, не второй
  нативный рендерер. До первого открытия карты — кнопка входа, без поддельных дорог.
- Локальный Valhalla Mobile 0.6.4 + Ferrostar 0.58.0: автомобильные маршруты,
  структурированные манёвры, привязка к маршруту и перестроение.
- Android LocationManager: только свежий немоковый GPS-фикс возрастом <=30 с
  с заявленной точностью <=100 м допускается как реальное начало маршрута.
  Подмена фиксированными координатами при отсутствии GPS не выполняется.
- Явный ручной просмотр: отдельная панель, подпись «НЕ GPS-ВЕДЕНИЕ».
- Поиск по локальному индексу OSM или координатам; удержание точки на карте.
- Русский Android TTS подключается пользователем при наличии локального голоса.
- В комплекте готовые PMTiles, индекс и граф из одного среза OSM:
  W=59.4 S=54.65 E=62.2 N=55.8. Челябинск, Миасс, Златоуст; не вся область.
  Исходный манифест/SHA-256: app/src/main/assets/navigation/bundled/manifest.json.
- Проверяемый импорт доверенного пакета .jelandnav.zip сохранён; ошибка импорта
  не заменяет активные данные. Маршрут перед импортом останавливается.
- Нет INTERNET permission, загрузчика карт, пробок, SDK-ключей или своего сервера.
  Существующие автомобили/климат/музыка/темы не заменялись версиями старой ветки.
- Сборка перенесена на ранее использованный навигационным прототипом JDK 21,
  Kotlin 2.3.20, AGP 8.13.2, Gradle 8.14.3, compileSdk 36; targetSdk остаётся 35.

## Проверка в этой итерации

Модульные тесты: 120, ошибок/падений 0. Итоговый APK: 26 Android-проверок,
ошибок 0, на локальном Android 11 BlueStacks (после перезапуска 127.0.0.1:5555).
Проверены собственная карта (обе темы и реальный снимок с дорогами/подписями),
полный размер вкладки, поиск и выбор координат, ручной просмотр/манёвр/геометрия,
четыре JNI-маршрута (город, аэропорт, Миасс, Златоуст), отказ за границей региона,
общий маршрут с главной, остановка и открытие климата поверх карты.
Также прошли главная/АКБ/топливо, климатические кнопки и отключение питания,
музыкальная строка, индикаторы/погода, задние сиденья, системная тема и 6 Room-тестов
базы автоматизаций. Установленный APK не запрашивает INTERNET permission.
Снимки MapLibre проверяются на непустое изображение; полный экран снимается
системным screencap (не UiAutomation.takeScreenshot). Итог: evidence/navigation-0.9.0-android.txt.

Первая проверка с Vulkan завершилась native SIGABRT в графическом RenderThread
BlueStacks (GL_INVALID_ENUM / SkiaOpenGLPipeline), до подтверждения карты.
Один только OpenGL не устранил сбой. В итоговом варианте оставлен один нативный
рендерер, убраны fade-переходы с картой и аппаратная маска скругления вокруг
TextureView; панели управления сохраняют скругления. Эмулятор затем был перезапущен.
После этих изменений карта и интерфейс прошли проверки; какая доля сбоя связана
с состоянием драйвера эмулятора, отдельно не доказано. Не считать ранние прогоны успешными.
Один поздний повторный прогон завис ещё до карты вместе со всем процессом HD-Player
и системными ADB-командами. Штатное закрытие не помогло; завершён только этот
тестовый процесс, затем запущен тот же экземпляр без удаления данных. Настройки
из прерванного теста явно восстановлены из его собственного сохранённого снимка.
После восстановления полный финальный прогон 26/26 прошёл за 40.758 с. Это не
доказывает длительную стабильность драйвера BlueStacks или реального ГУ.
Не выполнялась проверка на физическом ГУ, реальном GNSS или в движении.

## Проверка пользователем на стоянке

1. START → 1 → JelandOS-0.9.0-offline-navigation.apk. Это обновление, не удаление данных.
2. Открыть «Навигация»: карта должна занимать всю вкладку, меню и климат видны.
3. «Куда поедем?» → адрес в тестовом регионе или `55.165, 61.437` → результат.
4. Без GPS: «Просмотр» → «Старт в центре региона» → «Просмотреть маршрут».
   Должны появиться маршрут, манёвр, расстояние и подпись просмотра.
5. Главная → Навигация: маршрут один, камера сохраняется. Проверить +/−,
   «Весь маршрут», открытие климата поверх карты и завершение маршрута.
6. Шестерёнка → «Разрешить GPS»: разрешить точное местоположение. Дождаться
   свежего спутникового фикса, после завершения просмотра проверить «Поехали».
   На отсутствие фикса приложение должно ответить сообщением, не подставным стартом.
7. START → L для логов. Экспорт не должен копировать карты/графы/чужие APK.

## Ограничения

Нет пробок, широкой базы организаций, гарантии полноты адресов, камер/полос/онлайн
событий и вывода на приборку. Дорожные правила и граничные маршруты требуют
полевой проверки. Текущий маршрут не восстанавливается после убийства процесса.
GPS при уходе приложения в фон приостанавливается; фонового навигационного сервиса нет.
Публичный релиз как надёжного дорожного навигатора не заявляется.
