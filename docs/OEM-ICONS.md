# Штатные иконки ГУ

Общий набор `JIcons` использует ресурсы штатных приложений Jeland J7: SVHvac,
Launcher и SystemUI из сохранённого дампа ГУ. Значки аккумулятора и топлива
взяты из уже подключённого штатного набора приборки SOP6.

Реестр охватывает меню, климат, сиденья, рулевое колесо, зеркала, мультимедиа,
навигацию, общие кнопки и индикаторы связи. PNG/WebP копируются без изменения
байтов. Для Android-векторов сохраняются исходные viewport и pathData.
Прозрачные поля исключаются при показе; пропорции исходного изображения
сохраняются. Монохромные изображения получают цвет текущей темы, цветные
предупреждения и иллюстрации сохраняют свои цвета.

У вентилятора остаётся шкала из десяти сегментов. Его изображение — штатный
`SystemUI:mipmap/third_icon_wind`; вращения нет.

По отдельному запросу значок панорамной шторки заменён сгенерированным
монохромным изображением крыши со сдвигающейся шторкой. Прозрачный PNG
`ic_panoramic_shade_generated_v1.png` получает цвет текущей темы.
Это отдельный пользовательский ассет, а не ресурс прошивки; параметры генерации
сохранены в `assets/icons/custom/panoramic-shade.json`.

Для функций Jeland OS, у которых нет отдельного штатного пункта, используются
штатные символы по смыслу: часы для поездок и виджеты для автоматизаций.
Дорожные предупреждения без прямого штатного аналога получают штатный общий
предупреждающий значок; название и текст Стрелки сохраняются.
Иконки установленных сторонних приложений читаются из самих приложений.
Штатные контрольные лампы приборки сохраняют свои исходные изображения и цвета.

Происхождение, имена исходных ресурсов и SHA-256 сохранены в
`app/src/main/assets/icons/oem/provenance.json`. Восстановить импорт можно
скриптом `tools/import-oem-icons.py` (Python с Pillow):

```powershell
python tools/import-oem-icons.py --source-root <папка-сохранённых-APK> --aapt2 <путь-к-aapt2.exe>
```

Сам импорт не обращается к автомобилю, не меняет приложения ГУ и не загружает
сторонние наборы изображений.
