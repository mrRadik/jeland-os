# 0.6.5 — задние сиденья и направления обдува

ru.jeland.os, versionCode 23, versionName 0.6.5-rear-seats.

## Поведение

Открыть нижнюю правую кнопку сиденья пассажира. Вместо старого общего ряда
«Выкл. / левый / правый / оба» показаны два отдельных сиденья с реалистичной
иллюстрацией: заднее левое и заднее правое. У каждого собственные 0, 1, 2, 3;
0 означает выключить, остальные — уровень нагрева. Задней вентиляции нет.
Выбор и подпись независимы; передние переключатели сохранены.

SeatRepository.setRearLevel(RearSeatSide,level): для ГУ единственная запись
CAR 0x50001 / 139 (LEFT) либо /141 (RIGHT), VALUE=[level+1], ожидаемый GET=level.
Это уже разрешённые штатные каналы, новые CAN ID не угадывались.
Свежий статус проверяется только для выбранной стороны; отсутствие другой не
блокирует известную. Авторизация записи, foreground, busy и проверка эпохи
сессии остаются в DesayCarSession.command. Автоповторов SET нет.
Неизвестная сторона — «Нет данных» и неактивные кнопки; после SET уровень
не подделывается в телеметрии. Отдельные задние сиденья не зависят от HVAC power.

DEMO: отдельные ключи seat.rear.left.heat и seat.rear.right.heat, сохранение
после изменения. Миграция прежнего RearHeat: включённое место становится 1,
выключенное 0. Если новые ключи есть, они важнее legacy. Старый setRear для
совместимости поддерживает согласованные уровни и сводный RearHeat.
Новые проверки и команды не запускаются при установке/открытии сами собой.

В FACE/FEET убраны стрелочные наконечники, использованы мягкие потоки. Новый
JIcons.Windshield — только контур, используется исключительно для переключателя
направления «На лобовое». Иконки отдельного дефроста и обогрева не объединялись,
методы направлений/команд не изменены. Вращающийся вентилятор сохранён.

## Проверки

85 unit-тестов без ошибок: независимые значения, сохранение/legacy-миграция,
точные IDs/wire 0–3→1–4, разрешённость, неизвестные и просроченные каналы.
Целевой Android-прогон: OK (16 tests), включая новый UI и фиктивный Binder.
Полный общий Android-прогон: OK (60 tests), 0 ошибок, 140.678 с.
Снимки screenshots/qa-0.6.5/: rear-seats-dark/light, climate-airflow.
Подмена сервисов только в памяти BlueStacks 127.0.0.1:5556; физическая ГУ не
использовалась. Результаты реального подогрева проверяются отдельно на стоянке.

Фиктивный Binder проверяет ровно один SET только выбранной стороне для всех
восьми комбинаций side×level, работу без данных другой стороны, запрет без
fresh-target/разрешения записи и отказ от недопустимого уровня. UI проверяет
обе темы, независимость сторон/передних мест, выключение, неизвестную правую
сторону при доступной левой и отсутствие оптимистической подмены feedback.

Probe и режим MOCK автоматизаций не менялись.
