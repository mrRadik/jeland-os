# Jeland OS 0.3.1-mock — контекстные события кузова

## Изменения

- Постоянный VehicleStatusOverlay с дублирующей машиной удалён. Главный блок состояния сохранён на прежнем месте.
- Открытие на стоянке создаёт событие на 4000 мс. Каждая дверь, капот и багажник имеют отдельный срок; новые события не продлевают старые.
- Закрытие убирает соответствующее событие. После истечения времени открытая зона остаётся подсвеченной на основной схеме, но уведомление не повторяется от изменения других данных.
- Начало движения с открытой зоной включает постоянное предупреждение. Оно сохраняется до закрытия всего кузова, даже после остановки. Текст всегда обновляется по текущему набору открытых зон.
- Если всё закрыто, уведомлений нет. Нет кнопки случайного скрытия постоянного предупреждения.
- Вместо дополнительной машины используется компактный баннер с векторной иконкой; плавные fade/slide-переходы. Баннер ограничен по ширине, не перестраивает главную и не закрывает климат.
- По кузову открывается расширенная панель с независимыми DEMO-переключателями всех шести зон, тестовым движением и закрытием всех зон.
- По самому колесу или его показаниям открывается давление и температура именно этой шины. Значения обновляются реактивно; отсутствующие данные не выдумываются.
- Нормальные показания шин и фон кузова сделаны нейтральнее. Основная палитра, hero, расположение блоков, климат, меню, музыка и карта в этой правке не менялись.

## Архитектура

Чистый `VehicleNoticeReducer` в core принимает состояние кузова и монотонное время. `MainViewModel` наблюдает только изменения открытых зон/движения, публикует StateFlow уведомлений и ожидает ближайший срок. В простое нет опроса по таймеру; StateFlow других репозиториев не перезапускает уведомления. Переходы между разделами и пересоздание Activity не создают новый таймер.

Новых реальных автомобильных вызовов, системных уведомлений, разрешений, SDK, сервисов или прав root нет. Probe и ADB-коллектор не изменялись.

## Проверка

- Сборка debug APK и test APK успешна.
- Unit: 28 тестов, в том числе 8 сценариев времени/закрытия/повторного открытия/нескольких зон/фиксации предупреждения.
- Три новых UI-сценария прошли отдельным прогоном: автоматическое скрытие и раннее закрытие, четыре независимые шины в обеих темах, шесть DEMO-зон и постоянное предупреждение.
- Общий финальный прогон: **OK (17 tests)**, **106,881 с**, локальный BlueStacks / Android 11 при 1440×1920. Включены прежние проверки климата, тем, приложений, сворачивания и отсутствия прокрутки главной.
- Проверка геометрии подтверждает, что временный баннер не пересекает дату, часы, погоду и топливо в целевом разрешении. Сохранены 78 снимков, включая четыре шины в обеих темах, все закрытые зоны, открытые зоны после истечения уведомления и постоянное предупреждение.
- Android lint: 0 ошибок, 13 предупреждений (обновления зависимостей, портретная ориентация, правила backup для новых Android, прежняя сигнатура Glyph и два неиспользуемых drawable). Версии библиотек и ориентация автомобильного макета намеренно не менялись.
- Во время первого захвата изображения нативный UiAutomation эмулятора упал в takeScreenshot. Захват заменён на Compose root; повторная проверка прошла. В APK этот тестовый код не входит.

Снимки и журнал: `screenshots/v0.3.1/`. Снимки показывают только приложение, без внешних окон и системной клавиатуры.
После проверки временный размер экрана BlueStacks сброшен, Jeland OS открыт. На ГУ установка не выполнялась.
Физическая ГУ не использовалась. Работа на автомобильном железе, FPS и фактическая экранная IME этим прогоном не подтверждаются.
