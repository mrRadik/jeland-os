# Jeland OS 0.4.1 — иконки, приложения, вентилятор

## Изменения

- Вентилятор: общий FAN_MAX=10 в OEM-протоколе, allowlist, DEMO и интерфейсе.
  Никакого смещения: кнопка 10 → module 0x5000A / cmd12 / VALUE=[10], ожидается GET10.
  Ноль не отправляется в режиме ГУ: выключение отдельной кнопкой питания.
  Добавлены прямые ступени 1…10 и крупный индикатор, ползунок пишет после отпускания.
- Иконки: вместо принудительного toBitmap(96,96) — отрисовка полного Drawable в ARGB,
  сохранение пропорций, нормализация только прозрачных полей, восстановление bounds.
  Adaptive icon рисуется целиком, с официальной маской/фоном. Фон не удаляется по цвету.
  Если Drawable пуст или недоступен — общий значок, не падение всего списка.
- Приложения: адаптивная сетка, значки 68dp, единые рамки, заголовки в две строки,
  отдельная звезда и запуск по всей карточке. Редактор порядка виден в «Избранном».
  Те же нормализованные изображения используются на главной, её геометрия сохранена.

## Проверено 17.10.2026

- Сборка assembleDebug + assembleDebugAndroidTest — успешно.
- 46 unit-тестов, 0 ошибок, включая уровни вентилятора 1…10, запрет 0/11,
  неизменность OEM-кодов и пропорции квадратных/широких/высоких иконок.
- 8 экранных тестов в локальном BlueStacks, Android SDK30, serial 127.0.0.1:5556.
  Для QA временно 1440×1920; затем восстановлено исходное 1920×1080, плотность не менялась.
- Проверены реальные установленные значки, поиск и избранное, две темы;
  растровые wide/tall/padded, белый фон, adaptive и vector Drawable.
- Проверены + до 10, ограничение сверху, прямые 9/10, SetProgress ползунка до 8;
  главная без прокрутки и постоянная климатическая панель в разделах/панелях.
- Настройки DEMO сохранены/восстановлены через тестовый listener API приложения;
  JSON до/после совпадает побайтно. Root и изменение системных политик не использовались.
