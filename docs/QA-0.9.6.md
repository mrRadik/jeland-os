# 0.9.6 — одобренный образец №4

Пользователь прослушал восемь образцов и выбрал четвёртый для Speaker 1 и Speaker 7:
ударение U+0301 после «я» в «пятьдеся́т», 12 шагов синтеза. Именно эти изменения
применены; голоса и исходная модель не заменялись.

В `navigationSpeechText` ударение добавляется после разворачивания расстояния
в слова, только для целого слова «пятьдесят». Это охватывает 50, 150, 250 … 950 м.
Повторная обработка уже исправленной фразы не добавляет второй знак. Другие слова,
включая остальные числительные, не получают непроверенных исправлений. Текст
маршрута/виджета не меняется. Настройки темпа/громкости/выбранного пола не сбрасываются.
Одобренные образцы использовали темп 1,0; сохранённый пользовательский темп по-прежнему
имеет приоритет над значением по умолчанию.

12 шагов задаются общей функцией конфигурации для обоих sid; русский язык и
2 потока CPU сохранены. Модель, лицензия и нативная библиотека прежние.
Старые APK не удаляются и не перезаписываются.

Проверки: 157 JVM-тестов прошли, включая точную конфигурацию 12 шагов для обоих sid,
все расстояния с 50, идемпотентность исправления и неизменность экранного текста.
Корректность произношения образца подтверждена пользователем; это не обещание
идеальных ударений для всех названий улиц. На физическом ГУ задержка нового режима
ещё не измерена; большее число шагов увеличивает вычислительную работу.
