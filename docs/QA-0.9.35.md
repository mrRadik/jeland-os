# Jeland OS 0.9.35 — первая полная публикация

25 октября 2026 года. applicationId `ru.jeland.os`, versionCode **76**,
minSdk 30, targetSdk 35. Источники публикуются через отдельную ветку и PR в main.

## Содержание

- Полный текущий проект: интерфейс, реальное подключение ГУ, мультимедиа,
  автоматизации, офлайн-навигация, история и избранное, обновления.
- Исправление режима карты «по ходу движения»: общий курс экрана/виджета,
  резерв по перемещению и геометрии маршрута, удержание курса на остановке,
  восстановление поворота без ожидания нового GPS-фикса.
- README для пользователей и разработчиков, действующая лицензия с ФИО
  правообладателя, лицензии сторонних компонентов в исходниках и APK.
- Старые модели Supertonic, APK, журналы, ключи и кэши исключены из Git.

## Границы проверки

Новая версия не устанавливалась на физический ГУ. Поворот карты в реальной
поездке и обновление из опубликованного релиза на ГУ ещё не проверены.
Изменение направления обдува после команды вентилятора остаётся открытым
вопросом; новых команд климата в 0.9.35 не вводилось.

Репозиторий остаётся приватным до решения владельца. Проверка обновлений на
ГУ без авторизации заработает после открытия репозитория и релиза.
