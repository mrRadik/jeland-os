# Jeland OS 0.9.1 — номера домов

main, ru.jeland.os, versionCode 42. Изменены данные карты, слой подписей
и защита жизненного цикла навигационной сессии. Климат и команды автомобилю не менялись.

## Причина отсутствия номеров

Прежний сборщик карты сохранял kind/name/highway, но не addr:housenumber.
Адресный поиск содержал эти значения, а MVT-слой — нет. Одного изменения
цвета/масштаба подписей было недостаточно: добавлены реальные адресные точки.

## Подготовка и показ

- Инструмент: tools/add-navigation-house-numbers.py. Только локальный
  region.osm.pbf из того же исходного среза, без сети и генерации номеров.
- У адресного здания берётся точка внутри геометрии (не центр bbox, который
  может оказаться вне Г-образного здания). Отдельные адресные узлы сохранены.
- Если точка с тем же номером и совместимой улицей лежит внутри адресного
  здания, её повторная подпись удаляется. Разные номера не объединяются.
- Новый слой MVT addresses добавляется к zoom 15 исходного PMTiles без
  повторного кодирования исходных слоёв дорог/зданий. В приложении он
  отображается с zoom 16: обычный overzoom адресных точек из z15.
- Поле house_number сохраняет исходные корпуса/литеры/дробные номера.
  Масштабируемый шрифт, ореол и запрет пересечения подписей в обеих темах.
- Суммы search.json и valhalla_tiles.tar совпадают с 0.9.0. Маршруты/поиск
  не перестраивались. Исходная карта 0.9.0 и её APK сохранены.
- Встроенная карта проверяется по новым SHA-256 и обновляется с APK.
  Для известного старого исследовательского PMTiles-пакета выполняется
  переход на новую встроенную карту только по точному ID и SHA-256 старой
  карты; его прежняя папка не удаляется. Произвольные импортированные карты
  не переключаются и не выдаются за обновлённые.

## Проверка

123 модульных теста, ошибок 0. Проверка подписей на Android: номера действительно
отрисованы нативным MapLibre, источник addresses, minzoom 16; при отдалении до
14 номера отсутствуют. Реальные снимки сделаны через screencap в обеих темах.
Первый тест зависел от живого GPS эмулятора и не прошёл порог количества подписей
после перемещения камеры. Исправлен тестовый источник: явно помеченная симуляция,
без изменения пользовательских разрешений и реальной работы GPS приложения.
Финальный набор: 185 044 адресные точки, удалено 811 дублей адресных узлов
внутри зданий с тем же номером. Добавлен слой в 3 673 тайла. SHA-256 карты:
586ed9ee661bad4d64c7a9a661d970883c94570cfb5c958c4204f2ec6c38524b.

Финальная Android-проверка: OK (13 tests), 29,112 с — навигация, обе темы,
номера домов, отсутствие дубля у здания 177, скрытие при отдалении,
поиск/маршруты, общий маршрут, остановка, главная и климат. Отдельный повтор
стресс-теста: OK (1 test), 1,819 с. Только локальный эмулятор 127.0.0.1:5555,
не физический автомобиль. Пользовательские настройки восстановлены слушателем QA.

Во время регрессии найден реальный сбой Ferrostar: stopNavigation отменяет
сбор координат без ожидания завершения callback и уничтожает нативную сессию.
Параллельный callback обращался к уже уничтоженному объекту. NavigationSessionGate
сериализует целый callback координат со стартом/остановкой; исключение не подавляется.
Добавлены два модульных теста блокировки/отмены и Android-стресс-тест 12 циклов
маршрута при непрерывной подаче явно тестовых координат. Поиск и граф не менялись.
Снимки: docs/evidence/navigation-0.9.1-houses-{dark,light}.png.

Выданный APK: JelandOS-0.9.1-house-numbers.apk, 201 363 329 байт,
SHA-256 9069671cfd1b154911c2b1eed3dd90777666d9d5b1aeb9f11084c9a1fe4216b3.
Копии в artifacts и папке установщика имеют одинаковую контрольную сумму.

## Проверка пользователем

START → 1 → JelandOS-0.9.1-house-numbers.apk → Навигация → приблизить карту (+).
Отдельный импорт встроенного региона не нужен. На обзорном масштабе номера
намеренно скрыты. Если номера нет в OSM, он не придумывается. Покрытие не
равнозначно полной адресной базе 2ГИС. Полевые ограничения навигации 0.9.0 остаются.
