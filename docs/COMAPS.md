# Навигация CoMaps

CoMaps встроен в Jeland OS как библиотека. Отдельное приложение CoMaps устанавливать
не нужно. Вкладка «Навигация» и карта на главном экране используют одну сессию.

## Использование

1. Откройте «Навигация» → настройки карты → «Скачать карты».
2. Выберите страну и регион. Рядом с регионом нажмите «Скачать».
   Для подключения с оплатой трафика сначала включите «Разрешить мобильную сеть».
3. Дождитесь статуса «Установлена». Подробные карты, поиск и построение маршрутов
   по загруженным регионам выполняются на устройстве.
4. Найдите адрес или организацию либо нажмите на объект карты, затем «Поехали».
   Для начала ведения нужно разрешение GPS и свежее точное местоположение.
   Синяя кнопка со стрелкой включает слежение и поворот карты по ходу движения.
   Такой же переключатель есть в настройках карты. Запрос до появления GPS
   сохраняется и применяется после первого точного сигнала.
5. Карты можно удалить из того же списка. Активный маршрут сначала нужно завершить.

Обзорная карта мира, включая Россию, входит в APK. Она не заменяет подробные
регионы для адресного поиска и автомобильных маршрутов. Для поездки через несколько
регионов скачайте все регионы по пути. При отсутствии карт движок сообщает,
какие регионы необходимы.

Интернет используется для загрузки и обновления данных с серверов CoMaps.
Потоковые карты без загрузки региона и пробки не подключены.
Озвучка использует существующий RuVoice и его настройки в Jeland OS.
История поиска и избранные точки остаются в приложении.
После нажатия «+» или «−» выбранный масштаб сохраняется; кнопка слежения
снова включает автоматический масштаб по скорости.

Во время ведения верхняя карточка показывает ближайший манёвр, а компактная
нижняя — время прибытия и остаток пути. Камера учитывает место, занятое
карточками, и оставляет автомобиль видимым с запасом карты впереди.
Название улицы произносится в первом предупреждении перед манёвром; следующие
напоминания короче. Отдельно озвучиваются начало ведения, перестроение маршрута,
прибытие и ручная остановка. Прибытие определяется состоянием маршрута CoMaps.
На круговом движении карточка и значок показывают номер съезда, который
передаёт движок; голос произносит его как «первый съезд», «второй съезд» и т. д.
Перестроение озвучивается один раз за цикл отклонения от маршрута. Старая
линия удаляется на время расчёта новой, ведение и слежение сохраняются.

CoMaps — единственный движок навигации Jeland OS. Старые пакеты
`.jelandnav.zip`, PMTiles и графы Valhalla больше не используются. Для перехода
скачайте нужные регионы через встроенный каталог CoMaps. Сохранённые избранные
точки и история поиска сохраняются при обновлении приложения.

## Сборка

Дополнительно нужен Python 3.11 или новее. Подготовьте закреплённые исходники:

```powershell
git submodule update --init third_party/comaps
.\gradlew.bat assembleRelease
```

Рекурсивная загрузка подмодулей CoMaps не нужна: JNI-обёртки и ресурсы SDK
собираются из исходников, нативные библиотеки берутся из готового выпуска.
Задача `prepareCoMaps` автоматически скачивает и проверяет:

- APK CoMaps `v2026.10.05-19` с Codeberg: ARM64 и сгенерированные ресурсы;
- APK того же выпуска с F-Droid: библиотека x86_64 для эмулятора;
- обзорные `World.mwm` и `WorldCoasts.mwm`, проверяемые по метаданным выпуска.

Хеши и исходный коммит закреплены в `tools/prepare-comaps.py`.
Кеш загрузок находится в `.local/comaps`, подготовленные файлы — в
`comaps-sdk/build/upstream`. Они не добавляются в Git. Потребуется примерно
200 МБ сетевых загрузок при первой сборке; следующие используют кеш.

Исходники CoMaps закреплены на `7f3b5be834f7f73abca08339b4e56dcaf1b5ec3e`.
Изменения хоста находятся в `comaps-sdk` и `navigation/comaps`; исходники
подмодуля не меняются. Лицензия Apache-2.0, NOTICE и сведения о сторонних
компонентах включены в APK; данные OpenStreetMap имеют условия ODbL.

## Локальная DEMO-сборка

Для просмотра в BlueStacks:

```powershell
.\gradlew.bat :app:assembleDebug -PlocalDemo=true -PlocalDemoAbi=x86_64
```

Она автоматически включает демонстрационные данные автомобиля. В навигации
откройте настройки карты → «Демо-поездка». При необходимости сначала скачается
небольшая карта Андорры, затем движение проигрывается по маршруту CoMaps.
Координаты в этом режиме являются имитацией. Кнопка завершения маршрута
останавливает демонстрацию. Релизная сборка не предоставляет этот режим.
При наличии локального ключа подписи сборка может устанавливаться поверх
официальной версии с сохранением настроек и карт; без ключа используется
обычная debug-подпись. Параметр `localDemoAbi` предназначен только для эмулятора.
