# Jeland OS 0.6.8 — BT / CarPlay

main, ru.jeland.os, versionCode 27. Навигационный эксперимент отдельно;
Probe, шторка, климат и датчики этой доработкой не менялись.
Полевой разбор: FIELD-20261019-probe11.md.

Перенесены четыре подтверждённые команды Probe: PLAY, PAUSE, PREVIOUS, NEXT.
BT — VDBTService, event 262948; CarPlay — PhoneLink CLS, сервер 1, dataId 6,
пара DOWN/UP с обязательным отпусканием даже при ошибке/уходе после DOWN.
Неработающий старый CarPlay MediaSession dispatch и глобальные медиакнопки
НЕ используются. Метаданные CarPlay читаются из его MediaBrowser/MediaController.

Главный виджет и раздел «Музыка» показывают реальные title/artist/playback/position.
В live нет демо-треков/поддельной обложки/искусственного таймера или мгновенной
подмены playing. Исчезновение данных, stale, неподключённый BT, busy или запрет
записи отключают кнопки. В DEMO прежнее поведение и коллекция сохранены отдельно.
На главной используется выбранный в «Музыке» канал; никакого автоперехвата CarPlay
из-за старых метаданных. Источник хранится отдельно от настройки DEMO.

Выбор Bluetooth/CarPlay означает только клиентский маршрут, не смену реального
аудиоисточника. Нажатие выбранного канала повторно — ручное переподключение API.
Телефон и воспроизведение нужно подготовить штатно. CarPlay CLS bind без AUTO_CREATE,
без pairing, открытия устройства, запроса audio focus или переключения источника.
Подключение/пауза приложения не отправляют PLAY, PAUSE, STOP. Ошибки не повторяют
действие и не перенаправляются молча в другой канал. Кэш MediaSession сам по себе
не доказывает наличие подключённого телефона; OS не заявляет обратного.

Перемотка, дистанционное избранное, выбор трека из чужой коллекции и изменение
громкости не подтверждались Probe, поэтому в live отключены/скрыты, а не симулируются.
Для команд используется существующее разрешение управления интеграцией ГУ;
штатные BT/Wi-Fi разрешения приложения не расширены. Добавлены только queries
для BT и CarPlay пакетов. Root, priv-app, новые signature permissions не нужны.

## Установка и полевая проверка

1. START → 1 → JelandOS-0.6.8-phone-music.apk; обновление поверх старой версии.
2. На стоянке подключить ГУ и разрешить управление. Штатно запустить BT-аудио.
3. OS → Музыка → Bluetooth. Проверить название/исполнителя, PLAY/PAUSE и NEXT/PREV.
4. Штатно запустить CarPlay-аудио, вернуться в OS, снова разрешить управление
   после ухода из приложения, затем OS → Музыка → CarPlay.
   Проверить те же кнопки и главный музыкальный виджет. Если API был недоступен,
   нажать CarPlay повторно: это ручное подключение, не автоматический повтор команды.
5. Отключить телефон: данные/кнопки не должны превращаться в DEMO. Кэш CarPlay
   может ещё оставаться; никакой команды без собственного нажатия не отправляется.
6. START → L забирает журналы OS автоматически: MEDIA_ROUTE_SELECTED,
   MEDIA_BIND, MEDIA_REQUEST, MEDIA_SENT, MEDIA_FEEDBACK или MEDIA_ERROR.
   После ошибочного нажатия не повторять много раз — сначала сохранить этот лог.

Шины/наружный датчик и аппаратная маршрутизация приборки остаются отдельными
исследованиями. Инженерный режим приборки не включается этим APK.
