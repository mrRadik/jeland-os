# Jeland OS 0.9.3 — голос, загрузки и обзор России

2026-10-21, main, ru.jeland.os, versionCode 44.

## Голос

NavigationVoice и VoiceAnnouncementPolicy: автоматически включённый русский
офлайн-голос, выключение/громкость сохраняются. Установленный русский голос
Android без требования сети читает полноценную инструкцию с названиями улиц.
Если такого голоса нет, воспроизводятся 12 локальных WAV-фраз: повороты,
разворот, прямо, круговое движение, прибытие; заранее и непосредственно у манёвра.
Встроенные фразы не читают произвольные улицы и не называют выдуманную дистанцию.
Они синтезированы локально Microsoft Irina Desktop скриптом tools/build-navigation-voice.ps1.

Озвучка привязана к реальным шагам и порогам 1000/500/200/50 м, а не к каждому
GPS-обновлению. Ручной просмотр молчит; кнопка «Проверить голос» работает отдельно.
Android AudioAttributes: ASSISTANCE_NAVIGATION_GUIDANCE / SPEECH; кратковременный
аудиофокус MAY_DUCK освобождается после фразы/остановки. Запоздалые задания после
stop блокируются generation token. Устаревший SDK TTS observer не подключён —
двойной озвучки из двух реализаций нет. Фоновое GNSS-ведение/сервис не добавлялись.

## Загрузка карт

NavigationDownloads использует системный DownloadManager; процесс приложения
не обязан жить до окончания передачи. Состояние восстанавливается по ID.
Перед стартом проверяются HTTPS, редиректы только на HTTPS, размер по HEAD,
лимит 512 МБ и свободное место. ETag передаётся как If-Match, если сервер его
предоставил. По умолчанию запрещены тарифицируемые сети, роуминг всегда запрещён.
Есть прогресс, отмена и отдельная установка; завершение передачи не меняет
текущую карту и не останавливает маршрут. При отмене HEAD до постановки в очередь
загрузка не должна стартовать позднее. Пакеты без сообщённого сервером размера
или с неподдерживаемым HEAD отклоняются; нужна прямая файловая ссылка.

SHA-256 автора можно ввести; несовпадение блокирует установку. Если сумма автора
не задана, это явно написано, собственный хэш не выдаётся за проверку подлинности.
Для Jeland .jelandnav.zip остаются проверки имён, размеров, SHA файлов, состава,
поискового индекса и формата. Для подложки Protomaps PMTiles v3 проверяются
заголовок, диапазон метаданных, ограниченная распаковка и earth/roads/places.
Плохой файл не заменяет прежнюю подложку. Проверки целостности — не подпись автора;
UI требует подтверждения известного пользователю источника.

INTERNET теперь нужен для запрошенных загрузок. Рендеринг карты и Valhalla
остаются локальными; провайдер маршрутов по-прежнему запрещает HTTP-routing.
Погода и остальные автомобильные каналы не менялись. Сервера каталога нет,
несуществующих ссылок/кнопок скачивания регионов не добавлено. Можно скачать
уже подготовленный пакет по прямой ссылке, но не произвольный OSM PBF,
не картографические файлы Яндекс/2ГИС и не любой чужой Valhalla tar.

## Обзор России

Встроенный PMTiles: 6 494 875 байт, 1194 адресуемых тайла, zoom 0–6,
SHA-256 920ed56e1464de9fd4743e4906d43385552308ca4cecf3d3d347c3a734f8103b.
Отдельная подложка под детальным регионом; обзор не расширяет область доступной
маршрутизации. На z0–3 сохранён мировой контекст, на z4–6 — российские
ограничивающие области с окружением, включая Дальний Восток через линию дат.
Не утверждается точное совпадение прямоугольного охвата с границей государства.

Инструмент tools/build-russia-overview.py читает выбранные HTTP-диапазоны
Protomaps 20261020, ETag закреплён в manifest. В MVT сохранены только исходные
слои earth/water/roads/places/boundaries, без повторного кодирования геометрии
и без домов/landcover. Оригинальные слои сжаты gzip заново. Карта распространяется
в APK: приложение не hotlink-ит публичный planet-архив. Поле downloadedBytes
в отчёте — объём использованных диапазонов, включая локальный кэш, не общий
сетевой расход всех попыток подготовки. Это только обзорная степень подробности.
Для плавного входа на высоком портретном дисплее используется читаемый обзорный
масштаб, не whole-country fit с принудительным сдвигом камеры к экватору.

Источник: [Protomaps downloads](https://docs.protomaps.com/basemaps/downloads),
[схема слоёв](https://docs.protomaps.com/basemaps/layers),
[PMTiles v3](https://github.com/protomaps/PMTiles/blob/main/spec/v3/spec.md).

## Проверка

142 модульных теста, ошибок 0. Голосовые WAV декодированы Android, проверено
реальное начало/остановка MediaPlayer/TTS. HTTPS-передача проверена на небольшом
публичном текстовом файле PMTiles specification, с пересозданием контроллера
и неправильной SHA-256: текстовый файл не выдавался за установленную карту.
Валидная подложка и отказ плохой замены проверяются в отдельном QA Context/каталоге,
без изменений пользовательского активного региона. Снимки обеих тем инспектируются.
Финальный прогон после холодного старта: OK (21 tests), 40,959 с — 8 навигационных,
2 аудио, 2 настоящих HTTPS-загрузки, 1 атомарная установка/отказ плохой замены,
1 главная и 7 климат. До последних защит отмены/очереди голоса также был полный
успешный прогон 20 тестов (40,126 с). Прерванный ANR прогон не засчитан.
При первом тесте обзора плотность цветов оказалась ниже городской (37 отсчётов):
проверка низкого zoom отделена от городской, дополнена реальными feature queries
roads/places и ожиданием нужной темы; снимки сохраняются и при провале.

Выданный APK: JelandOS-0.9.3-voice-maps.apk, 210 140 118 байт,
SHA-256 8c133bafd264a645ff6306793352e751beb6a81e8daa8319b64a679814421edf.
Копии artifacts/установщика идентичны. Исходные настройки до/после QA совпадают.
В artifacts также подготовлены самостоятельный обзор PMTiles и текущий регион
.jelandnav.zip для будущего размещения; внешнего URL у них пока нет.

Один повторный UI-прогон завершился ANR при потере фокуса MainActivity в
эмуляторе. Это не считается успешной проверкой, причина не установлена.
Пользовательские настройки восстановлены сохранённым снимком перед новым запуском.
Проверка не доказывает долгосрочную стабильность native GL/GUI и работу аудиоканала
на физическом ГУ. Физический автомобиль не подключался.

## Распространение регионов

Отдельный вычислительный сервер для раздачи файлов не нужен. Возможны обычное
HTTPS-хранилище или GitHub Releases (ограничения проверять перед публикацией).
Текущий тестовый ZIP ~64 МБ, 100 похожих по объёму пакетов ~6,4 ГБ; 15–20 ГБ —
пример запаса для такого набора с обновлениями, не размер подробной всей России.
Никакие файлы/репозитории в интернете в ходе этой задачи не публиковались.
