# Jeland OS 0.7.8 — прокрутка музыкальных метаданных

20 октября 2026, versionCode 37.

Название трека и исполнитель во всех вариантах MediaWidget занимают одну
строку без переноса и многоточия. Прокрутка включается только при переполнении:
28 dp/с, пауза перед началом и повтором 1800 мс. Новый текст начинает движение
с начала. Переводы строк в метаданных заменяются пробелами.

Размеры карточки, музыкальные команды и выбор источника не изменены.
