# Jeland Map Builder — подготовка карт

Инструмент создаёт готовый `.jelandnav.zip` из исходного файла OpenStreetMap.
Внутри находятся карта, номера домов, адресный поиск, дорожный граф и манифест.
Пересобирать Android-приложение для новой карты не нужно.

## Быстрый запуск в Windows

1. Установите **Python 3.12 x64** с [python.org](https://www.python.org/downloads/windows/).
   При установке включите добавление Python в PATH.
2. Запустите **MAP-BUILDER.cmd** в папке проекта или распакованного сборщика.
   При первом запуске он скачает библиотеки в собственную папку `.local`.
   Права администратора, Docker, Android SDK и ключи API не нужны.
3. Скачайте исходный **`.osm.pbf`** с [Geofabrik](https://download.geofabrik.de/russia.html).
   Это исходные данные OSM, а не карта Яндекса/2ГИС и не готовый ZIP.
4. Выберите файл, задайте название и ID карты, выберите **новую** папку результата.
5. Для части большого исходника включите «Обрезать по границам» и заполните четыре
   координаты. Для целого скачанного региона оставьте переключатель выключенным.
6. Нажмите **«Собрать карту»**. Дождитесь сообщения **«ГОТОВО»**.

Первый запуск требует интернет для библиотек. Сама сборка из уже скачанного PBF
работает локально. Готовые пакеты не публикуются автоматически.

## Что вводить в окне

| Поле | Пример и значение |
|---|---|
| Исходный OSM-файл | `D:\Maps\ural-fed-district-latest.osm.pbf` |
| Название карты | `Челябинск · центр` — название для пользователя |
| ID / имя пакета | `chelyabinsk-center` — строчные латинские буквы, цифры и дефис, до 64 символов |
| Новая папка результата | `D:\Maps\result\chelyabinsk-center-20261026` — ещё не должна существовать |
| Ссылка на источник | Страница Geofabrik, с которой скачаны данные; попадёт в манифест |
| Потоки | Начните с 2; больше потоков потребует больше памяти |

Для нового региона используйте новый ID. Для обновления того же региона сохраните
ID и имя ZIP, но выберите новую папку результата. Старые исходники и результаты
инструмент не перезаписывает.

## Как выбрать границы

Откройте [OpenStreetMap](https://www.openstreetmap.org/) и инструмент «Экспорт»:
он позволяет выделить прямоугольник и показывает его координаты.
**Скачивать XML-экспорт не нужно** — перенесите границы в сборщик и используйте PBF Geofabrik.

Порядок: **западная долгота, южная широта, восточная долгота, северная широта**.
Для центра Челябинска: `61.38`, `55.14`, `61.43`, `55.18`.
Десятичный разделитель — точка; в графическом окне также допускается запятая.
Выбирайте область с запасом: маршрут не сможет выехать за её пределы и вернуться.
Исходный PBF должен покрывать весь выбранный прямоугольник.

Вырезка сохраняет полные дороги, их узлы и связанные ограничения поворотов.
Рисунок карты и поиск ограничиваются выбранной областью. Населённый пункт
берётся из явного адреса или содержащего его полигона OSM, а не из ближайшего города.
Недостающие в OSM адреса и номера домов сборщик не выдумывает.

## Что получится

В выбранной папке:

- **`<id>.jelandnav.zip`** — готовый пакет для приложения и GitHub;
- **`build-report.json`** — размеры, количества адресов, версии инструментов,
  контрольная сумма и координаты проверочного автомобильного маршрута;
- **`SHA256SUMS.txt`** — контрольная сумма ZIP;
- **`maps.json`** — каталог для собственного HTTPS-хранилища;
- **`GITHUB-RELEASE.txt`** — краткая памятка по публикации;
- `map.pmtiles`, `search.json`, `valhalla_tiles.tar`, `manifest.json` — содержимое пакета;
- `.build` — промежуточные данные и журнал `graph.log`.

Перед выдачей пакета проверяются обязательные файлы, размеры, контрольные суммы,
структура PMTiles и TAR. Дополнительно строится реальный автомобильный маршрут
движком Valhalla 3.9.1. Его координаты записываются в отчёт.
Один такой маршрут подтверждает работоспособность графа, но не полноту дорог всей области.

## Публикация на GitHub

1. В `mrRadik/jeland-os` создайте **новый обычный релиз с картами**.
2. Прикрепите **`<id>.jelandnav.zip`** без переименования.
3. В подписи файла (**Label**) укажите понятное название из поля «Название карты».
   Если Label не задан, приложение покажет имя файла.
4. В описании укажите область покрытия, дату данных и атрибуцию
   `© OpenStreetMap contributors · ODbL 1.0 · Geofabrik` со ссылкой на источник.
5. Опубликуйте релиз. Не оставляйте Draft/Pre-release и **не назначайте его latest**
   для приложения.
6. В Jeland OS откройте «Скачать карты» и обновите список круглой кнопкой.

В релиз можно прикрепить несколько разных регионов. Для GitHub файл `maps.json`
не обязателен: приложение распознаёт пакеты по расширению `.jelandnav.zip`.
При одинаковом имени ZIP выбирается самый свежий опубликованный релиз.
Обновление уже установленной карты пока выполняется через «Удалить» → «Скачать».

Для собственного сервера разместите ZIP и `maps.json` **в одной HTTPS-папке**.
В приложении укажите ссылку на эту папку или непосредственно на `maps.json`.

## Ограничения текущего приложения

| Содержимое | Максимум |
|---|---:|
| Скачиваемый ZIP | 512 МиБ |
| Сумма распакованных файлов | 512 МиБ |
| Карта `map.pmtiles` | 128 МиБ |
| Поиск `search.json` | 32 МиБ / 250000 записей |
| Граф `valhalla_tiles.tar` | 400 МиБ |
| Манифест | 64 КиБ |

Если лимит превышен, сборщик выдаст ошибку. Уменьшите область или разделите её
на несколько пакетов. Вся Россия одним подробным регионом в эти лимиты не помещается.
Соседние пакеты сейчас не объединяются для сквозного маршрута: активен один подробный регион.
Обзорная карта России — отдельный уже подготовленный файл; этот инструмент строит подробные регионы.

Ресурсы зависят от исходника и числа объектов. Для первых городских сборок разумно
иметь 16 ГБ ОЗУ и несколько гигабайт свободного SSD. Проверка запуска требует минимум
1 ГиБ свободного места, но это не оценка потребления для произвольной большой области.

## Проверка готового пакета и команды

В окне есть **«Проверить ZIP»**. Она проверяет структуру, размеры и SHA-256,
но не пересобирает граф и не меняет карту в приложении.

Из терминала в папке проекта:
В примере `example-region.json` сначала укажите путь к своему скачанному OSM-файлу.

```powershell
.\MAP-BUILDER.cmd doctor
.\MAP-BUILDER.cmd build --config tools/map-builder/example-region.json
.\MAP-BUILDER.cmd validate "D:\Maps\result\chelyabinsk-center.jelandnav.zip"
.\MAP-BUILDER.cmd pack "D:\Maps\prepared-region" --output "D:\Maps\release\chelyabinsk-center.jelandnav.zip"
```

`pack` предназначен для уже подготовленных совместимых файлов с манифестом;
он проверяет их, но не превращает случайную PMTiles-карту в навигационный регион.
Пути в JSON-конфигурации считаются относительно самого JSON, не текущей папки терминала.
Настройки можно сохранять и загружать кнопками в окне.

## Если сборка остановилась

- «Python 3.12+ required» — установите Python 3.12 x64 и повторите запуск.
- Ошибка загрузки библиотек — проверьте интернет; повторный запуск продолжит подготовку среды.
- «Папка результата уже существует» — выберите новую папку, чтобы не затереть предыдущую карту.
- «Исходный OSM неполный» — нужен полный PBF, а не вырезка с отсутствующими узлами дорог.
- «Нет автомобильных дорог» — проверьте координаты и покрытие исходника.
- «Граф не прошёл проверку» — посмотрите `.build\graph.log`; такой результат не публикуйте.
- Ошибка размера — уменьшите область. Не увеличивайте лимиты только в сборщике: приложение их не примет.
- После «Остановить» результат остаётся незавершённым. Для повтора выберите новую папку.

Версии основных библиотек закреплены в `tools/map-builder/requirements.txt`.
Не обновляйте Valhalla отдельно: формат графа должен оставаться совместимым с приложением.

[Pyosmium BackReferenceWriter](https://docs.osmcode.org/pyosmium/latest/reference/Data-Writers/),
[PMTiles](https://docs.protomaps.com/pmtiles/), данные [OpenStreetMap](https://www.openstreetmap.org/copyright).
