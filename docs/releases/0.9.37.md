# Jeland OS 0.9.37

- Альтернативный главный экран с крупным автомобилем, навигацией, музыкой, давлением шин и шкалами топлива и аккумулятора. Классический вариант остаётся доступным в настройках.
- Температура на главном экране помещается в одну строку; ярлыки и подписи избранных приложений учитывают увеличенный системный шрифт и высоту экрана ГУ.
- Карты скачиваются из GitHub Releases или собственного HTTPS-каталога. Установленные карты можно удалить из приложения.
- На ГУ без рабочего системного сервиса загрузки карты скачиваются напрямую с сохранением частичного файла и проверкой SHA-256.
- Исправлена ручная загрузка обновлений через Wi-Fi телефона; добавлены обработка результата установки и сообщения об ошибках.
- Включение и выключение автоматизации сохраняет порядок сценариев.
- Состояние панорамной шторки отображается на большом автомобиле; управление остаётся в компактном окне.
- Температура шин убрана из интерфейса, давление сохранено.
- Добавлен инструмент подготовки собственных пакетов карт и инструкция: [MAP-BUILDER.md](../MAP-BUILDER.md).

Устанавливайте APK поверх прежней версии: подпись сохранена. В релиз включён `jelandos-update.json` для проверки обновления из приложения.

Проверка: сборка Android, модульные тесты, Android Lint, компиляция Android-тестов; проверки интерфейса и загрузки карт на BlueStacks. Физический ГУ в этих проверках не подключался. Полную установку обновления и особенности прошивки ГУ необходимо проверить на машине.

Тестовый релиз с тегом `v0.9.37`, опубликованный ранее, сохранён. Этот выпуск использует тег `v0.9.37-hu-fixes`, версию приложения `0.9.37` и versionCode 92. Исходники выпуска находятся в ветке PR и в теге выпуска; слияние в `main` выполняет владелец через PR.
