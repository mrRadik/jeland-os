# Jeland OS 0.9.35

Первая полная публикация проекта: интерфейс Jeland J7, управление климатом
и комфортом, музыка Bluetooth/CarPlay/USB, состояние автомобиля,
автоматизации, офлайн-навигация и обновления через GitHub.

В навигации исправлен режим «по ходу движения»: карта и виджет используют
единый курс, направление восстанавливается при отсутствии GPS-bearing,
на остановке карта не сбрасывается на север. Кнопка возврата к автомобилю
восстанавливает поворот сразу. Сохранены история, избранное и голос RuVoice.

Добавлены README и действующая лицензия. Правообладатель — Файсханов Радик
Ринатович. Бесплатное использование, изменение и бесплатные адаптации разрешены;
продажа и платный доступ без отдельного разрешения запрещены. Добровольные
донаты разрешены. Сторонние компоненты сохраняют собственные условия.

## Установка

Скачайте APK из Assets и установите поверх прежней версии. Версия 0.9.35,
versionCode 76, Android 11+. Подпись сохранена от предыдущей линии сборок.
Для озвучки нужен отдельно установленный оригинальный RuVoice 1.1.1:
https://github.com/kost-t-human/ruvoice-tts/releases/tag/v1.1.1.

`jelandos-update.json` предназначен для механизма обновления Jeland OS.
`SHA256SUMS.txt` содержит контрольные суммы файлов.

## Проверка и известные ограничения

307 JVM-тестов прошли; релизная сборка, vital lint и компиляция Android-тестов
успешны. Подпись и состав APK проверены. На физическом ГУ эта версия ещё
не проверялась; Android UI-тесты в этой публикации не запускались.

Встроен тестовый регион Челябинск — Миасс — Златоуст и обзор дорог России;
подробной карты и дорожного графа всей страны нет. Пробки не подключены.
Температура шин зависит от доступности канала QNX; исследование побочного
переключения обдува при смене вентилятора продолжается.

Исходники выпуска находятся в ветке `release/0.9.35` и в теге релиза.
Включение проекта в main выполняется отдельным PR по решению владельца.
Пока репозиторий приватный, релиз доступен только имеющим доступ к нему;
обновление с ГУ без авторизации потребует публичного репозитория.
