# Jeland OS 0.7.7 — аккумулятор

20 октября 2026, versionCode 36. Новый BatteryReading с nullable-полями,
BatteryDecoder, карточка между передними колёсами и Popup.BATTERY.
DEMO-показания задаются отдельно в MockVehicleRepository, не используются
LiveVehicleReducer и не сохраняются как реальные данные.

## Чтение

К существующей подписке и GET-циклу CarInfo 0x50004 добавлены только:

| CMD_ID | Значение | Пересчёт |
|---:|---|---|
| 76 | напряжение бортсети | uint16 BE / 10 В |
| 96 | заряд АКБ | один байт 0..100 % |
| 97 | оценка SOH | один байт 0..100 % |
| 109 | ток | четыре байта; диапазон по байту 1, uint16 BE из байтов 2/3 |
| 110 | напряжение IBS | uint16 BE / 1024 + 3 В |
| 111 | температура АКБ | байт - 40 °C |
| 113 | пусковое напряжение SOF | байт * 0.0625 В |
| 115 | ток покоя | байт / 256 А |

Для тока 109: диапазон 0 -> raw/1024-32, 1 -> raw/128-256,
2 -> raw/16-2048 А. Направление тока текстом не интерпретируется.

Источник формул: локальная декомпиляция EngMode,
work/engmode-jadx/sources/com/desaysv/engmode/model/impl/BatteryInfoActivityModel.java
в рабочем каталоге чата. Там инженерные CAN-ответы; их полезные данные
сопоставлены с CarInfo-кэшем от 19 октября. Это не объявляется подтверждённой
калибровкой на автомобиле. В подробностях есть соответствующая оговорка.
SOH не подменяет диагностику исправности батареи.

Запросы SV_SEND_CAN_LINK_DATA из EngMode не переносились. Новый функционал
не содержит SET и не меняет правила разрешённых команд. Запись в INFO запрещена.
Применяются существующие IS_NULL-проверка и срок свежести 15 секунд. Неверные
размеры/байты, неизвестный диапазон тока, 0xFF/0xFFFF-сентинелы и неправдоподобные
напряжения/температуры отбрасываются. Настоящий нулевой процент не теряется.

## Проверка

Сборка, 106 модульных тестов успешны. Четыре новых BatteryReadingTest:
полевой fixture, отсутствие/формат/сентинелы, устаревание/null/clear и разделение
модулей (seat cmd96 не заряд), read-only whitelist и настоящий ноль.

DashboardPolishInstrumentation прошёл на локальном BlueStacks 127.0.0.1:5556
при размере 1920x1440 (приложение 1440x1920), обе темы. Проверены геометрия
между передними шинами, видимость 14,6 В, открытие и закрытие панели с 13 °C.
Размер эмулятора восстановлен, DEMO-настройки восстановлены QaPreferenceGuard.
Снимки: outputs/jelandos-077-battery-qa в рабочем каталоге чата.

На физическое ГУ не устанавливалось. После обновления включить интеграцию ГУ,
нажать аккумулятор и сравнить показания со штатным инженерным экраном;
собрать START -> L для raw GET/EVENT. Не включать инженерные запросы ради
заполнения отсутствующих значений.
