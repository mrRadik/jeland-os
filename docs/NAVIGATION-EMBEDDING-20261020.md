## Итог для текущего подхода

Полная карта установленных неизменённых приложений внутри Compose-вкладки
обычного Jeland OS APK на проверенном Android 11 недоступна. Выдавать запуск
в отдельном окне или текст уведомлений за полную интеграцию нельзя.
Новая «полная» версия не выпускается: опубликованный 0.8.0 не перезаписан.

NavigationEmbeddingAuditInstrumentation выполнен на локальном Android API30
от UID Jeland OS, без root, shell identity, привилегий или захвата чужих окон.
Создан временный собственный виртуальный дисплей. Официальный
ActivityManager.isActivityStartAllowedOnDisplay вернул false для launch и
route Intent обоих реально установленных навигаторов:

```
SDK=30
Host=ru.jeland.os
ACTIVITY_EMBEDDING=false
INTERNAL_SYSTEM_WINDOW=false
MANAGE_ACTIVITY_TASKS=false
INJECT_EVENTS=false
DGIS.launch.allowedOnOwnDisplay=false
DGIS.route.allowedOnOwnDisplay=false
YANDEX.launch.allowedOnOwnDisplay=false
YANDEX.route.allowedOnOwnDisplay=false
```

Дисплей и ImageReader освобождены. Этот тест — проверка разрешённости запуска,
а не получение картинки или интерактивная встроенная навигация. На физическом
ГУ OEM-расширения этим тестом не проверялись; нельзя распространять результат
на неизвестную привилегированную службу прошивки.

Проверены манифесты официальных 2ГИС 7.29.1.632.4 и Яндекса 31.1.3, скачанных
в предыдущем шаге. allowEmbedded для окон карты не найден. В обоих есть
CarAppService для Android Auto, но одно наличие экспортированной службы
не доказывает, что она примет наш собственный хост. HostValidator предусматривает
проверку сертификата/системного разрешения; переговоры с этими службами
и выдача Surface не реализованы и не объявляются работающими.

В исходниках AOSP Android11 ActivityStackSupervisor.isCallerAllowedToLaunchOnDisplay
для виртуального дисплея обычного UID проверяются FLAG_ALLOW_EMBEDDED и
ACTIVITY_EMBEDDING. Обычный публичный virtual display не снимает эту проверку.
Современное Activity Embedding требует поддержки платформы и доверия целевого
приложения. Это не способ произвольно вставить чужой APK в Compose на API30.

## Доступные направления, требующие нового решения пользователя

1. Официальный SDK карт/навигации внутри Jeland OS. Это настоящее собственное
   представление карты, без переноса окон установленных APK. Нужны ключи,
   согласованные условия использования и, для соответствующих функций,
   лицензия/оплата. Офлайн-данные и профиль установленного приложения не следует
   считать автоматически доступными SDK. Это изменение архитектуры/условий.
2. Системный OEM-хост для окон приложений/автомобильных шаблонов. Сначала нужны
   подтверждённый интерфейс прошивки и законные права доступа. Работоспособность
   на этом ГУ не установлена. Root/priv-app, патч навигаторов, чужие сертификаты,
   установка системных компонентов или обход HostValidator не выполнялись.

Ни подписка Яндекс Плюс сама по себе, ни разрешение overlay сами по себе не
делают наш APK доверенным автомобильным хостом. WebView сайта — другое решение,
не офлайн-навигация установленных приложений, поэтому здесь не подставляется.

## Проверки правок

BUILD.ps1 -Tests успешно, 111 модульных тестов. 7 инструментальных тестов:
NavigationEmbeddingAudit (1), InstalledNavigation (5), DashboardPolish (1).
Проверены выбор из SettingsScreen, сохранение провайдера, отсутствие селектора
на вкладке навигации, кнопка перехода к настройкам, редактор мест, Intent,
уведомления, отсутствие новой демонстрационной карты и прежняя главная.
Настройки тестов восстановлены QaPreferenceGuard. Никакие системы автомобиля
не запускались и права приложения не расширялись.
