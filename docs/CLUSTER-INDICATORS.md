## Подключение нативного потока — 11 ноября

В код Jeland OS подключено чтение a000/a00d через пассивный FTP на 60005.
Таблица выше отражает исследование на 10 ноября; теперь декодер нативного a00d
передаёт EPB, Auto Hold, Start/Stop, передние ремни, состояние холодного/горячего
двигателя и найденные аварийные лампы. Короткие Android FAULT-пакеты по этой таблице
не интерпретируются. Native a000 содержит отдельные цифровые обороты, скорость
и температуру ОЖ. Обороты Android /62 по гипотезе raw*4 не восстанавливались.

Для текстовых предупреждений используется индекс из a00d и OEM-таблица перехода
к ресурсам TextWarn/TextMinWin: 224 статических текста на русском и английском.
ID 65535 снимает сообщение; ID 0 является реальным сообщением дистанционного запуска.
Динамические OEM-экраны с нулевым текстовым ресурсом не подменяются случайным текстом.

Проверено 20 целевыми JVM-тестами, включая FTP-обмен с локальным сервером,
и тестом BlueStacks на пакет между обновлениями таймера плюс отрисовку трёх дизайнов.
Нативные значения в этих проверках искусственные; новое чтение PPS через FTP
требует подтверждения на физическом автомобиле. Журнал CLUSTER_WARNING_NATIVE
содержит полный пакет и ID, CLUSTER_GAUGE_NATIVE — исходные данные приборов.

## Полный каталог отображения

Подключены все 130 именованных позиций таблицы SOP4, соответствующие 126 уникальным
состояниям. Повторные позиции одного имени объединяются; NULL и резервные биты
не интерпретируются. Каталог расположен в core/ClusterIndicatorCatalog.kt, точная
карта битов и соответствие картинкам — assets/cluster/oem/native-indicators.json.

Это общий декодер, а не отдельный обработчик для каждой вновь замеченной лампы.
Подключены свет, ремни по местам, EPB/Auto Hold/Start-Stop, тормоза, ESP/ABS/EPS,
двигатель, масло, зарядка, коробка, TPMS, полный найденный набор ассистентов,
сервисные и гибридные состояния из общей OEM-таблицы. Неактивные значки не показываются.
Наличие гибридных сигналов в общей таблице не означает наличие этих систем на J7.

Используются 112 оригинальных PNG без изменения исходных байтов. Позиции ремней
подписаны возле штатного символа. Для красного TJA используется оригинальный белый
символ этой системы с фиксированным красным цветом сигнала. Два ISA-состояния,
для которых в доступных ресурсах нет отдельных PNG, имеют текстовые обозначения.
Эти исключения явно перечислены в native-indicators.json; неизвестные картинки
не подставляются автоматически.

Переполнение верхней строки переносится в общий ряд значков. Все знаки остаются
видны при показе текста; состояние температуры и топливо отображаются внутри шкал.
Проверка каждого бита и оригинальности PNG проведена программно и в BlueStacks.
Реальное получение всех отдельных аварийных состояний автомобилем не подтверждалось.
