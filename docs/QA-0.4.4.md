# Jeland OS 0.4.4 / Probe 0.6 — локальная проверка

18 октября 2026:

- OS: assembleDebug, assembleDebugAndroidTest, 49 unit-тестов — без ошибок.
- 8 UI-тестов на локальном BlueStacks Android 11 / 127.0.0.1:5556, 1440×1920:
  две темы, полный автомобиль и открытые панели, привязка колеса, расчётное давление,
  неизвестная температура, короткое предупреждение, шторка без повторного диалога,
  избранное, главная без прокрутки, постоянный климат, управление fan до10 и сиденья.
- Снимки проверены в screenshots/qa-0.4.4. Preferences до/после совпадают побайтно.
- Исходное разрешение эмулятора 1920×1080 восстановлено.
- Probe: сборка 0.6 подписана прежним исследовательским ключом. 800 проверок
  Parcel/Binder в локальном Android с mock-сервисом — успешно; vehicle/BT сервиса
  эти тесты не получают и реальных команд не отправляют.
- Реальный Bluetooth-компонент и wire-схема сверены с APK из архива владельца.
- ADB Toolkit: 27 изолированных сценариев установки/удаления/сбора логов — успешно.

Не проверено физически: подавление OEM HVAC-панели, чтение/команды BT после исправления
компонента, окончательная калибровка шин/порядок справа, точные 50% шторки и RPM.
Android-снимок с меткой display2 не подтверждает её видимость на штатной приборке.
Подробные основания и следующий сценарий: FIELD-20261018.md.
