# Jeland OS 0.7.0 — музыка

## Изменения

- Главная: настоящая обложка, название, исполнитель и краткий источник; без
  инструкций «запустите музыку штатно» и повторения служебного статуса.
- Раздел «Музыка»: отдельный большой плеер, обложка и декоративная волна,
  остановленная на паузе. Это не анализ аудиосигнала; микрофон не используется.
- В LIVE источник берётся только из OEM CURRENT_SOURCE_TYPE, без ручных
  переключателей, угадывания по метаданным и автоматического запуска музыки.
- USB: штатный список композиций, подсветка текущего файла и выбор трека.
  Список перечитывается каждые 5 секунд; перед выбором проверяется повторно.
- Изменения 0.6.9 по погоде/климату сохранены, навигационный эксперимент не включён.

## Основания и ограничения

Реверс штатного `com.desaysv.ivi.vds.media`, каталог исследования
`work/system-jadx/media/sources` в рабочей папке Codex:

- `mediaservicelogic/a/h.java`: CURRENT_SOURCE_TYPE = 393217, значение VDMediaType
  получено через AudioFocusUtils.getCurrentMusicAudioSourceId(). IDs: BT 13,
  CarPlay 18, USB0 3, USB1 4. Радио/локальная музыка/AA не подменяются Bluetooth.
- `VDServiceDef`: com.desaysv.ivi.vds.media.service.MediaService,
  action.desaysv.ivi.vds.media.SERVICE, IVDBus.
- Метаданные 393218, статус 393220, время 393221. У unified media PLAYING=1,
  PAUSED=2, STOPPED=3; времена в миллисекундах. BT и CarPlay сохраняют свои
  проверенные отдельные пути управления и единицы времени.
- USB SDK: com.desaysv.moduleusbmusic.service.MusicAidlService в
  com.desaysv.svaudioapp (есть в package snapshot) либо com.desaysv.svmusicapp.
  Descriptor com.desaysv.localmediasdk.IAIDLMediaManager: tx6 getRemoteList
  (usb0/usb1, list_all), tx3 getCurrentPic, tx1 one-way sendCommand.
  play/pause/pre/next, set_media с source/mPath/mTitle из актуального списка.
- 393219 не используется как список песен: в этом OEM-адаптере его ответ
  VDMediaExtInfo.mediaList содержит URI первого файла, а не сериализованный плейлист.
- Обложки: BT art/icon, CarPlay MediaMetadata bitmaps, USB getCurrentPic;
  fallback VDMediaInfo.albumBuffer и разрешённые локальные content URI.
  Нет HTTP, доступа к произвольным файлам, скачивания или INTERNET permission.
  Вход до 2 МиБ, decode с ограничением размеров, результат до 512×512,
  загрузка/декодирование вне UI. Отсутствующая обложка — нейтральный диск.

Автоматический выбор, USB SDK и доступ к обложкам реализованы по OEM-коду,
но ещё НЕ подтверждены свежей проверкой этой сборки на физическом ГУ.
Проверенные пользователем BT/CarPlay команды сохранены, однако новый source gate
также требует полевой проверки. При недоступном/неизвестном источнике управление
отключается, а не отправляется в предположительный BT-канал.

## Защита

Источник опрашивается в foreground раз в секунду. Нет ответа >3 секунд —
метаданные скрыты и команды недоступны. Старые callbacks отклоняются по epoch.
Перед командой источник запрашивается повторно на worker; смена источника,
DEMO, пауза приложения или отзыв разрешения отменяют неподтверждённую команду.
Нет OPEN_SOURCE, автоматического PLAY, смены аудиофокуса, переподключения телефона,
глобальных media key, повтора команд, STOP/PAUSE при выходе. CarPlay UP сохраняется
после начатого DOWN даже при отзыве разрешения. Нет новых опасных permissions.

## Проверка на машине, на стоянке

1. Поставить JelandOS-0.7.0-music.apk через START → 1. В интеграции ГУ разрешить
   управление. Открыть «Музыка»: отсутствуют ручные переключатели LIVE.
2. Выбрать музыку Bluetooth штатно. Убедиться, что OS сама показывает Bluetooth,
   трек/обложку; проверить паузу/продолжение, назад/вперёд.
3. Штатно перейти на CarPlay. Через 1–2 секунды OS должна показать CarPlay,
   новую композицию/обложку. Повторить четыре кнопки.
4. Штатно выбрать USB с несколькими файлами. Проверить название, обложку,
   список и запуск другого файла из списка. Проверить переключение на второй
   USB, если он есть. Если обложки в файле нет, нейтральный диск — нормально.
5. Удалить флешку или выбрать радио. OS не должна продолжать управлять старым
   каналом. Вернуться на телефон: маршрут должен восстановиться автоматически.
6. Проверить краткую карточку на главной; собрать START → L.
   В журнале OS: MEDIA_AUTO_SOURCE, MEDIA_FEEDBACK, MEDIA_USB_LIST,
   MEDIA_SOURCE_* / MEDIA_USB_* при ошибке. Публичные тексты ошибок на экран не выводятся.
