# Jeland Map Builder 1.0.0 — проверка 26 октября 2026

Основной запуск: `MAP-BUILDER.cmd`. Пользовательская инструкция: `MAP-BUILDER.md`.
Приложение и его рабочие карты этой проверкой не заменялись.

## Результаты

- Чистая установка закреплённых зависимостей в собственную `.local/map-builder` — успешно.
- Повторная установка из распакованного standalone ZIP в отдельной папке — успешно,
  `doctor` подтверждает Python 3.12.10, pyvalhalla 3.9.1, osmium 4.3.1,
  shapely 2.2.0, pmtiles 3.8.1 и mapbox-vector-tile 2.2.0.
- 5 Python-тестов — успешно: ссылки и ограничения поворотов при вырезке пересекающей
  дороги, населённый пункт и адрес из содержащего полигона, исключение названия района
  вместо города, защита путей ZIP и отказ от незавершённых пакетов, бюджет тайлов.
- Окно Tk: поля, переключатель границ и размер запрошенной компоновки 617×768
  внутри начального окна 960×780 проверены. Скриншот окна отдельно не снимался.
- Валидатор принимает ранее опубликованный пакет тестовой зоны
  `192487ca1d45ed2a7724dc413206e2c27a79c480bdaa0b22a3cc83e6fef4e002`.

Проверена финальная сборка из реального локального OSM-фрагмента,
границы `[61.38,55.14,61.43,55.18]`. Данные карты, поиска и графа получены
из одного файла. Результат:

- `artifacts/map-builder-qa/run-4/chelyabinsk-builder-qa.jelandnav.zip`;
- 2204106 байт, SHA-256 `a216ee0d76a98ed29c92b6005f0109bf99f34db0bb052ac9b01d99e2a8682182`;
- 5025 записей поиска, 2425 адресных номеров, 75 MVT-тайлов, 3 тайла графа;
- автомобильный маршрут 122.785 м успешно рассчитан настольной Valhalla;
- тот же ZIP импортирован в изолированное хранилище Android 11 BlueStacks;
- настоящий Android JNI Valhalla рассчитал маршрут между теми же точками;
- MapLibre отрисовал новую карту, PNG визуально проверен;
- Android-тест `MapBuilderPackageInstrumentation` — `OK (1 test)`.

Доказательства: `artifacts/map-builder-qa/run-4/build-report.json`,
`artifacts/map-builder-qa/android/generated-region.png`, `accepted.txt`.
Android-тест использует отдельный временный каталог и не меняет активный регион пользователя.

до исправления запуска Windows CLI Valhalla; это была длительная проверка подготовки
данных, а не завершённый выпуск полного региона. Не выдавать промежуточный run-2 за
прошедший сквозную проверку пакет. Нативный запуск исправлен и проверен в run-4.
