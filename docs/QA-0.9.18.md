# 0.9.18 — запуск вместе с системой

22.10.2026. versionCode 59. Дополняет [описание функции 0.9.17](QA-0.9.17.md).

Промежуточная 0.9.17 была скопирована для установки до тестов по просьбе пользователя. Первый прицельный прогон: 8 проверок, одна ошибка — отсутствовал NEW_TASK в Intent запуска из BOOT receiver. Intent.makeMainActivity задаёт MAIN/LAUNCHER, но не эти флаги.

В 0.9.18 явно добавлены NEW_TASK и RESET_TASK_IF_NEEDED наряду с SINGLE_TOP. Тест дополнен проверкой RESET_TASK_IF_NEEDED. Остальная логика неизменна: default-off, пользовательское разрешение SYSTEM_ALERT_WINDOW, только BOOT_COMPLETED, один запрос Activity без повторов, без изменения штатного лаунчера/прошивки/команд автомобиля. Физическая загрузка ГУ ещё не проверена. Как и предыдущие устанавливаемые версии, используется подписанная debug-сборка, не отдельный Gradle release-вариант.

Сначала формируется готовый APK в artifacts и папке START, затем выполняются 8 прицельных Android-проверок. Полный набор тестов не запускается.

APK скопирован в обе папки до повторного запуска проверок. Размер: 471471590 байт; SHA-256 обеих копий: `C9D07E6FD6A4D7E026032ACC93A368352AD435D144A4D35C3A3B7EC089CA6920`. apksigner verify: v2 valid; aapt: package ru.jeland.os, versionCode 59, versionName 0.9.18-system-startup.

Результат: в BlueStacks Rvc64 / 127.0.0.1:5555 установлена именно выложенная копия APK, затем тестовый пакет. Два класса SystemStartupInstrumentation и SystemStartupUiInstrumentation: **OK (8 tests)**, 2.028 с. Проверены default-off, сохранение opt-in, точные события/флаги запуска, отсутствие фонового запроса разрешений, явный package-scoped экран разрешения, отказ без повторов, приватность receiver и UI off/pending/ready/off в обеих темах. QaPreferenceGuard восстановил настройки эмулятора. Это проверки подставного Context и UI: реальная полная загрузка ГУ не имитировалась и остаётся непроверенной.

Снимки настроек: `screenshots/qa-0.9.18/startup-dark.png`, `startup-light.png`. Визуально просмотрены: подписи читаемы, переключатель и готовность помещаются в панели. Прямоугольная подсветка строки на снимке — обратная связь после тестового нажатия. Полный набор тестов не запускался. После проверок APK не пересобирался и не изменялся.
