# 0.6.4 — иконки, температуры dock, анимация вентилятора

ru.jeland.os, versionCode 22, versionName 0.6.4-icons-climate.

## Иконки

39 пиктограмм импортированы из фиксированного lucide-static 0.468.0, без runtime
зависимости или сетевой загрузки. Источник: https://lucide.dev/guide/static,
лицензия: https://lucide.dev/license. Копия лицензии поставляется внутри APK:
app/src/main/assets/licenses/lucide.txt и feather-mit.txt для производных Feather.
Генератор: tools/Import-Lucide.ps1;
результат: ui/theme/LucideVectors.kt. Независимые SVG paths остаются отдельными,
чтобы относительные команды каждого path сохраняли собственное начало координат.

Стабильные имена JIcons сохранены, потребители не переписаны. Automotive: сиденье,
воздух лицо/ноги, электрический обогрев лобового/заднего стекла, обдув лобового,
руль, крыша, камера, зеркала, двери/капот/багажник. 24-unit сетка, оптическая
толщина 1.8–2, скруглённые штрихи. Одобренная форма рециркуляции сохранена.
Реалистичное колесо и остальные изображения автомобиля не заменялись векторами.

## Температура

Число в нижней постоянной панели: roundToInt, без десятичной части/знака градуса,
фиксированная ширина 44 dp, TextAlign.Center. LO/HI и неизвестное значение «—»
сохранены. Округление — только визуальное, никаких новых SET или иной шкалы.

## Вентилятор

Стандартный fan вращается вокруг своего центра через graphicsLayer.rotationZ,
linear infinite animation. Период 2440…1000 мс для ступеней 1…10.
Композиция анимации существует только при известном включённом питании и fan>0.
Нет свежих данных, выключен климат или fan=0 — статичная пиктограмма.
Смена скорости меняет только период; анимация не управляет автомобилем.
Нижняя кнопка всегда позволяет открыть меню даже при выключенном питании.

## Проверки

81 unit-тест без ошибок. Повторный общий Android-прогон: OK (56 tests), 0 ошибок.
В старых FieldFixes/HomeFavorites добавлено ожидание portrait, а чтение результата
команды шторки ожидает асинхронный StateFlow; первоначальные две гонки тестов устранены.

Unit: числовой формат, LO/HI/unknown/NaN, неизменность модели при округлении,
монотонный ограниченный период вентилятора. UI: атлас иконок в обеих темах,
целочисленные подписи и центрирование между кнопками, разные кадры работающего
вентилятора, одинаковые кадры остановленного, неизвестная ступень без анимации.

ДО композиции: автоматическое время Compose намеренно отменяет infinite animations.

Проверки выполняются локально в BlueStacks 127.0.0.1:5556, не на физической ГУ.
